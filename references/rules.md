# 病历书写通用规范（河北细则 + 协和逻辑）

本文件为**模式 A（病历书写）的总纲**。规范基准：**《河北省病历书写规范细则（2013年版）》（冀卫办医政〔2013〕30号）为主体**，**2023 版修订要点为补充**；书写逻辑参考**北京协和医院**优秀病历标准（详见 [pumch-style.md](pumch-style.md)）。

> 说明：条文如与本医院现行执行版本有出入，以医院现行规定为准，并在输出末尾标注待核对项。

## 一、总则
1. 病历书写遵循**客观、真实、准确、及时、完整、规范**六原则。
2. 病历是法律文书，内容必须有事实依据或医生的明确判断；禁止编造。
3. 日期采用**公历制**，按"年、月、日"顺序用阿拉伯数字书写；时间采用**24 小时计时制并记录到"分"**。
4. 度量衡统一采用**法定计量单位及国际符号**：血压用 mmHg，长度用米/厘米/毫米，容量用 mL/L；**严禁**"公尺、公分、公厘、公升、立升"。
5. 疾病分类编码按 **ICD-10**，手术/操作分类按 **ICD-9-CM-3**。
6. 使用中文和规范的医学术语；药物用**通用名**，不用商品名。

## 二、语言与表述
| 规范 | 说明 | 错误示例 |
|---|---|---|
| 症状具体量化 | 用可核实的量化描述 | "发热较高" → "体温最高 39.2℃" |
| 阴性体征具体化 | 逐个系统写阴性体征 | "查体无异常"、"(-)" |
| 避免主观推断 | 只写观察与医生判断 | "患者脸色难看" → "面色苍白，精神萎靡" |
| 药物用通用名 | 不得写商品名 | "拜新同" → "硝苯地平控释片" |
| 慎用缩写 | 首次出现写全称，括号注缩写 | "PTCA" → "经皮冠状动脉腔内成形术（PTCA）" |
| 不用歧义词 | 避免"很多、较重、好像" | "疼得厉害" → "VAS 8 分，夜间为甚" |
| 外院资料加引号 | 外院诊断、药名、检查结果加引号 | 写"外院按'肺部感染'治疗" |

## 三、时间要求与单项否决时限（2013 细则）

**下列为"单项否决"缺陷，一旦超时整份病历直接不合格：**

| 文书 | 时限 |
|---|---|
| 入院记录、再次或多次入院记录 | 入院后 **24 小时**内 |
| 首次病程记录 | 入院后 **8 小时**内 |
| 新入院危重患者上级医师查房记录 | **24 小时**内 |
| 主治医师首次查房记录 | **48 小时**内 |
| 科主任或副高以上医师首次查房记录 | **72 小时**内 |

其他时限：
| 文书 | 时限 |
|---|---|
| 日常病程记录（病危） | ≥1 次/日，病情变化**随时**记录，记录到分 |
| 日常病程记录（病重且稳定） | ≥1 次/**2 日** |
| 日常病程记录（普通且稳定） | ≥1 次/**3 日**（2023 修订删除旧版"5 日"规定） |
| 新入院患者病程 | 连续记录 **3 天** |
| 抢救记录 | 抢救结束 **6 小时内**据实补记 |
| 出院记录 | 出院后 **24 小时内** |
| 死亡记录 | 死亡后 **24 小时内** |
| 转科记录 / 交接班记录 / 会诊记录 | 相应事件后 **24 小时内** |
| 死亡病例讨论记录 | 死亡后 **1 周内** |

## 四、书写资质（2013 细则）
- **首次病程记录**：必须由**本院注册的执业医师**书写；实习、试用期及进修人员**不能**书写。
- **入院记录**：实习、试用期或进修医师可书写，但**必须由本院注册执业医师带教签名负责**；实习医师代写视为缺入院记录（单项否决）。
- **所有签名**：一律签署**全名**，杜绝缩写、简称；电子病历打印后**必须补充手写签名**（2023 补充）。

## 五、修改规范（2013 细则）
- 错字用**双横线划掉**，保留原记录**清晰可辨**，注明**修改时间和修改人全名**。
- **禁止**刮、粘、涂、描；手写及打印病历中**每页修改不超过 3 处、每处不超过 20 字**。
- 电子病历按卫生部《电子病历基本规范（试行）》执行，经**电子签名**确认；已完成录入、打印并签名的电子病历**不得修改**。

## 六、主诉书写
- 为主要**症状（或体征）+ 部位 + 持续时间**，语言简洁，一般**不超过 20 字**，时间数字用阿拉伯数字。
- **一般不以诊断或检验结果为主诉内容**。
- 主诉与现病史的时间必须一致。

## 七、现病史
- 按**时间顺序**记录：发病情况 → 主要症状特点及发展变化 → 伴随症状 → 诊疗经过及结果 → 一般情况变化 → **与鉴别诊断有关的阳性或阴性资料**。
- 围绕主诉**逐层递进**展开（协和逻辑），不流水账，不追叙既往史内容。
- 外院诊断、药名加引号。

## 八、体格检查
- 依次：一般情况（神志、发育、营养、体位、合作度）→ 生命体征 → 皮肤黏膜 → 淋巴结 → 头颈部 → 胸部（肺、心）→ 腹部 → 脊柱四肢 → 神经系统。
- **阳性体征详细描述**；**阴性体征也要具体**；专科检查与主诉、诊断、鉴别诊断相关者**充分描述**。

## 九、诊断书写（2013 细则 + 2023 补充）
- 诊断分四类（2023 补充）：**初步诊断、修正诊断、补充诊断、出院诊断**。
- 入院时一律写"**初步诊断**"，书写在入院记录**末页中线右侧**。
- 住院期间需**修正或补充诊断**时，须由**主治医师及以上资质**医师书写并签名、注明日期。
- **出院诊断**由主治医师及以上作出，书写在**末页左侧**。
- 按主次排序：主要疾病在前，并发症/合并症在后；"待查"不确诊诊断并列。

## 十、知情同意书（2023 补充）
- 手术同意书、麻醉同意书、输血治疗知情同意书等，患者不仅要**签字**，还要**签署意见**（如"同意手术"）。

## 十一、院外辅助检查（2023 补充）
- 入院前在其他医疗机构所做的检查，应**写明机构名称、检查号及检查日期**，按检查日期顺序分类记录。

## 十二、常见错误清单（校验必查）
- [ ] 首次病程 / 入院记录 / 查房记录超单项否决时限
- [ ] 主诉超 20 字 / 用诊断或检查结果做主诉 / 与现病史时间矛盾
- [ ] 现病史流水账、未逐层递进、与既往史重复
- [ ] 阴性体征用"无异常"一笔带过
- [ ] 药物出现商品名；计量单位用"公斤/公分/公升"等
- [ ] 时间格式非 24 小时制或未到分
- [ ] 诊断未按主次排序 / 无初步/修正/补充/出院分类
- [ ] 签名缩写；电子病历未手写签名；知情同意书未签意见
- [ ] 修改超每页 3 处每处 20 字或未保留原记录
- [ ] 院外检查缺机构名称、检查号、日期
