# 入院记录模板（2013 年版规范 + 协和逻辑）
> **版本 v1.14.2（2026-09-16）**｜依据：《河北省病历书写规范（2013年版）》（冀卫办医政〔2013〕30号），**本院现行制度优先**；标注「2023 补充/修订」的条目来源待核验（见 [rules.md](rules.md) 的「来源与核验状态」）。

书写时限：**入院后 24 小时内**（单项否决）。四类：入院记录 / 再次或多次入院记录 / 24 小时内入出院记录 / 24 小时内入院死亡记录。

书写资质：实习、试用期、进修医师可书写，**必须由本院注册执业医师带教签名负责**。

## 书写要点

1. **主诉**：症状（或体征）+ 部位 + 持续时间，≤20 字；**不用诊断或检查结果代替**；与现病史时间一致。
2. **现病史**：围绕主诉**逐层递进**——发病诱因 → 首发症状 → 主要症状特点及演变 → 伴随症状 → 就诊与检查经过 → 一般情况变化；**写出与鉴别诊断有关的阳性与阴性资料**；外院诊断、药名、检查结果加引号。
3. **既往史**：疾病史、手术外伤史、**输血史**、**过敏史**、传染病史、预防接种史。**过敏史必须明确写**（无则写"无"）；**本次住院有输血者，诊疗过程中须记录血制品品种、数量、时间及有无输血反应**。
4. **个人史 / 婚育史 / 家族史**：与本次疾病相关的写详细。
5. **查体**：生命体征必须有具体数值；阳性体征详尽、阴性体征具体；专科检查与主诉、诊断、鉴别诊断相关者充分描述。
6. **辅助检查**：按检查日期顺序记录；院外检查须写明**机构名称、检查号、检查日期**。
7. **初步诊断**：书写于**末页中线右侧**，按主次排序（主要疾病在前，并发症/合并症在后）。

## 常见缺陷

| # | 缺陷 | 正确做法 |
|---|---|---|
| 1 | 超 24 小时完成（单项否决） | 入院后 24 小时内完成 |
| 2 | 主诉超 20 字，或用诊断/检查结果做主诉 | 改为症状或体征 + 部位 + 时间 |
| 3 | 现病史流水账、与既往史重复、缺鉴别相关阴性资料 | 围绕主诉逐层递进 |
| 4 | **缺过敏史**；输血者未写有无输血反应 | 既往史明确写出过敏史；输血者记录品种、数量、时间、反应 |
| 5 | 阴性体征写"无异常""(-)" | 逐系统具体描述 |
| 6 | 院外检查未写机构名称、检查号、检查日期 | 逐项补全 |
| 7 | 实习/进修医师独自签名 | 本院注册执业医师带教签名 |
| 8 | 初步诊断未写在末页中线右侧、未按主次排序 | 按规定位置与顺序书写 |

## 自检

- 机检：`python scripts/validate_note.py <正文文件> --kind admission --admit "<入院时间>"`
- 人工：主诉与现病史时间一致；过敏史/输血史齐备；院外检查三要素；诊断位置与排序；签名资质。
