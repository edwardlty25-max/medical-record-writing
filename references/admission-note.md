# 入院记录模板（河北细则 + 协和逻辑）

书写时限：**入院后 24 小时内**（单项否决）。四类：入院记录 / 再次或多次入院记录 / 24小时内入出院记录 / 24小时内入院死亡记录。

书写资质：实习、试用期、进修医师可书写，**必须由本院注册执业医师带教签名负责**。

## 要点
- **主诉**：见 [rules.md](rules.md) 第六节——≤20 字、不用诊断/检查结果、症状在前病程在后。
- **现病史**：协和逻辑——围绕主诉**逐层递进**，非流水账；与主诉时间一致；写有鉴别意义的阳性/阴性资料。
- **查体**：生命体征必须有具体数值；阳性详尽，阴性具体；专科检查充分描述。
- **辅助检查**：院外检查注明**机构名称 + 检查号 + 检查日期**。
- **初步诊断**：按主次排序；入院一律写"初步诊断"，位于末页中线右侧。
