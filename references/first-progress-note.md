# 首次病程记录模板（原则与模板见一页版，本页为展开说明）

> **只要原则和模板？** 先看 [progress-and-first-note-principles.md](progress-and-first-note-principles.md)（一页版：五条总原则 + 首程/病程/术前小结/术后病程/查房模板 + 句式 + 常见错）。本页是展开说明，按需查。
> 依据：《河北省病历书写规范（2013年版）》（冀卫办医政〔2013〕30号），**本院现行制度优先**；标注「2023 补充/修订」的条目须与本院现行版本核对（见 [rules.md](rules.md)）。

书写时限：**入院后 8 小时内**（单项否决）。书写资质：**仅限本院注册执业医师**，实习、试用期、进修人员不能书写。

格式：第一行居中写"首次病程记录"；第二行顶格写记录时间（24 小时制，如 `2026-08-05 14:30`）；内容换行书写；签名独占一行，在下一行右端。

## 书写要点

1. **五部分缺一不可**：病例特点、初步诊断、诊断依据、鉴别诊断、诊疗计划。
2. **病例特点**：对病史、查体、辅助检查**全面归纳分析**，要点清晰、文字简洁——是归纳，不是照抄入院记录。
3. **初步诊断**：分层写——主要诊断 → 并发症/严重程度 → 影响处理的合并症；已确认的写诊断名称，未确认的写"待查"。
4. **诊断依据**：逐条对应病例特点中的事实（病史/查体/检查），**体现个人诊断思路**，避免"公式化"。
5. **鉴别诊断**：围绕主问题列 2～4 项，每项写"支持点 / 不支持点 / 用什么检查区分"；优先排除危及生命或会改变处置的疾病。
6. **诊疗计划**：按"**问题—目标—处理—监测—调整**"写，具体可执行；**具体药物须写通用名、剂量、途径、频次、疗程**，缺项标【待医生确认】，不得写"继续原治疗""进一步检查"。
7. **病例特点要写"证据链"**：症状特点 + 危险因素 + 查体所见 + 辅助检查数值**指向同一结论**，让读者看出诊断是怎么"推"出来的，而不是特征罗列。
8. **有手术/介入可能者，诊疗计划要写出"术前计划"**：拟行术式的指征依据、术前需完善的检查、术前用药与抗凝安排、术前讨论与知情同意的安排、不做手术的替代方案。（术前的正式小结与确认见 [progress-note.md](progress-note.md) 第七节）
9. **并发症与合并症必须处理到位**：影响本次处理的合并症（高血压、糖尿病、肝肾功能异常、饮酒史等）要同时出现在初步诊断与诊疗计划中，不能只在病例特点里提一句。
10. **时间**：≤ 入院后 8 小时；与入院记录、体温单时间一致。

**病例特点里最容易漏的两类证据**

| 类型 | 为什么要写 | 示例 |
|---|---|---|
| **有意义的阴性结果** | 用于鉴别诊断（否则鉴别就成空话） | "无咯血、无呼吸困难，D-二聚体正常" |
| **定量与来源** | 让审阅者可回溯 | "高敏肌钙蛋白 I 0.08 μg/L（参考 <0.03 μg/L，2026-09-10 当地医院）" |

## 模板

```
首次病程记录

2026-08-05 14:30

病例特点：
1. 一般情况：____（年龄、性别、入院途径：门诊/急诊/他院转入等，入院时间须与体温单一致）
2. 起病与症状：因"____"入院，____（主要症状、起病缓急、演变）
3. 既往史要点：____
4. 查体要点：____（阳性体征 + 有意义的阴性体征）
5. 辅助检查阳性结果：____

初步诊断：
1. ____（主要诊断）
2. ____（并发症/严重程度，如有）
3. ____（合并症或影响当前处理的风险因素，如有）

诊断依据：
（1）____
（2）____

鉴别诊断：
（1）与____鉴别：____（支持点与不同点）
（2）与____鉴别：____

诊疗计划：
1. 问题与目标：____（当前优先解决的问题及短期治疗目标）。
2. 检查计划：____（拟完善的检查、目的及结果如何影响诊断或处理）。
3. 病因/靶向治疗：____（适应证、治疗方向；具体药物须写通用名、剂量、途径、频次、起始时间和计划疗程，缺项标【待医生确认】）。
4. 对症支持与并发症防治：____（处理目的、安全核对及预防策略）。
5. 护理、监测与调整：____（护理级别、饮食、生命体征/出入量、复查项目、调整或升级条件）。
6. 医患沟通与宣教：____（诊断不确定性、方案收益风险及患者/家属意见）。

（签名独占一行，右端）
医师签名：________
```

## 有手术/介入时的首程写法（重点）

**病例特点**：除常规五项外，必须归纳出**手术指征相关事实**——症状特点与持续时间、危险因素、心电图/心肌损伤标志物/影像结果（带数值与来源）、影响手术安全的合并症（肾功能、肝功能、凝血、感染）。

**初步诊断**：术后病例的诊断要分层——主要诊断 → 严重程度/分型（如"不稳定型心绞痛""高血压病 3 级（极高危）"）→ 合并症（如"酒精性肝损伤"）。

**诊疗计划（手术病例专条）**：

```
3. 术前计划：____（拟行术式全称 + 指征依据；术前需完善的检查及目的；
   抗血小板/抗凝药物的停用或桥接安排；禁食禁水、备血、皮肤准备；
   术前讨论与知情同意的安排时间；不手术的替代方案及其局限）。
4. 围手术期监测与并发症防治：____（术前生命体征与心电监测、血压控制目标；
    术后常见并发症的观察与防范：出血、感染、基础病加重等；
    抗凝/抗血小板治疗的出血风险监测；切口或局部情况的观察）。
```

**写"术前计划"时的三不要**：不写"拟择期手术"（要写日期与术式全称）；不写"必要时手术"（要写指征与条件）；不写"术前检查待定"（要写具体项目与目的）。

## 诊断变更怎么写进首程与病程

首程写的是**初步诊断**，住院期间一旦有修正/补充诊断，不要回改首程（首程是原始记录，不得修改），而要在**病程记录**中按五要素留痕（见 [progress-note.md](progress-note.md) 第九节）：

| 要素 | 写法 |
|---|---|
| 诊断名称 | "补充诊断：肺结节" / "修正诊断为：不稳定型心绞痛" |
| 依据 | 具体检查 + 数值 + 单位 + 参考范围 + 报告时间与来源（院外项目写机构与检查号） |
| 时间 | 依据的发现时间与本次记录时间 |
| 对治疗的影响 | 加用/停用/调整了什么，或仅随访观察 |
| 资质与签名 | 主治医师及以上书写、全名签名、注明日期 |

> 首程、病程、出院诊断必须形成**诊断链**：首程写初步诊断 → 病程写依据与变更 → 出院诊断逐条对应。只在出院记录里出现的新诊断，视为留痕不全。

## 常见缺陷

| # | 缺陷 | 正确做法 |
|---|---|---|
| 1 | 超 8 小时完成（单项否决） | 入院后 8 小时内完成 |
| 2 | 由实习/进修/试用期人员书写 | 仅限本院注册执业医师 |
| 3 | 病例特点照抄入院记录 | 归纳分析，条目化，突出阳性与有意义的阴性 |
| 4 | 诊断依据与病例特点脱节、写"公式化"套话 | 每条依据对应具体事实（时间、数值、来源） |
| 5 | 鉴别诊断凑数或只写病名 | 写支持点、不支持点、区分检查 |
| 6 | 诊疗计划笼统（"继续原治疗""进一步检查"） | 按问题—目标—处理—监测—调整写具体 |
| 7 | 药物只写类别或商品名，无剂量疗程 | 通用名 + 剂量 + 途径 + 频次 + 疗程，缺项标【待医生确认】 |
| 8 | 记录时间与入院记录/体温单不一致 | 通篇核对时间 |
| 9 | 有手术可能却不写术前计划（只写"必要时手术"） | 写出术式、指征、术前检查、抗凝安排、讨论与同意时间、替代方案 |
| 10 | 病例特点罗列事实但不成证据链 | 症状 + 危险因素 + 查体 + 检查数值指向同一结论 |
| 11 | 合并症只在病例特点出现，诊断与计划里没有 | 同时写入初步诊断与诊疗计划（监测目标与用药注意） |
| 12 | 鉴别诊断缺"有意义的阴性结果"支撑 | 在病例特点与鉴别诊断中写明关键阴性结果与区分检查 |

## 自检

- 机检：`python scripts/validate_note.py <正文文件> --kind first-progress --admit "<入院时间>"`
- 人工：五部分齐全；诊断依据可回溯；鉴别诊断有区分检查；诊疗计划可执行；签名资质。
