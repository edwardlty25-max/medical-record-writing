# 转科记录 与 死亡相关记录（2013 年版规范）

## 一、转科记录

转科记录由**转出科室**书写，转科后 **24 小时内**完成。

```
转科记录

入院日期：____  转科日期：____
患者姓名：____  性别：____  年龄：____  住院号：____
病情及诊疗经过：____（入院以来的主要病情、诊断、治疗）
转科原因：____
目前诊断：1. ____  2. ____
转科后注意事项：____
转出科室医师签名：________（全名）
```

转入科室在患者入科时书写**转入记录**（病情、查体、转入后处理），同样 24 小时内完成。

## 二、死亡记录

死亡后 **24 小时内**完成，由经治医师书写。

```
死亡记录

患者姓名：____  性别：____  年龄：____  住院号：____
入院日期：____  死亡日期及时间：____
入院诊断：
1. ____
诊疗经过：____（入院以来病情演变、主要治疗、抢救过程简述）
死亡原因：____
死亡诊断：1. ____
记录时间：____
记录医师签名：________（全名）
```

死亡时间写具体（`YYYY-MM-DD HH:MM`）；**死亡原因**与**死亡诊断**要区分。

## 三、死亡病例讨论记录

死亡后 **1 周内**完成，参加人员为科内医师。

```
死亡病例讨论记录

患者姓名：____  住院号：____
讨论时间：____  讨论地点：____
主持人：____  参加人员：____
病例汇报：____（病情、诊疗经过、抢救经过）
讨论意见：
1. 诊断是否明确，诊断依据是否充分
2. 治疗是否合理、有无延误
3. 死亡原因分析，有无教训
4. 改进措施
结论（主持人总结）：____
记录医师签名：________（全名）
```
