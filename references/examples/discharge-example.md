# 示例：出院记录（**虚构数据**）

<!-- kind=discharge -->

> ⚠ 全部数据、药物与剂量均为虚构，仅示范格式与颗粒度；**不得作为用药依据**。

## 一、输入（医生口述）

> 患者住院 7 天，肺炎治好了，今天出院。入院时发热咳嗽，现在不烧了，咳嗽明显好转、没有痰。
> 住院期间头孢曲松 2g 每日一次静滴共 5 天，同时继续氨氯地平 5mg 每日一次控制血压，复查血常规正常、
> 胸片片状影吸收。出院带药再吃 3 天，让他 1 周后门诊复查胸片。

## 二、输出（正文）

```
2026-09-22 10:00
入院日期：2026-09-16　　出院日期：2026-09-22
入院情况：患者男性，67 岁，因"发热伴咳嗽、咳痰 1 天"于 2026-09-16 入院。入院前 1 天出现发热，最高 39.1℃，伴咳嗽、少量白痰，无胸痛、无咯血。入院查体：T 38.6℃，P 96 次/分，R 22 次/分，BP 132/82 mmHg，右下肺呼吸音低、可闻及湿啰音。辅助检查：血常规白细胞 12.3×10⁹/L、中性粒细胞 82%，胸片示右下肺片状影。
入院诊断：1. 社区获得性肺炎　2. 高血压 2 级
诊疗经过：入院后予头孢曲松 2g 每日一次静脉滴注抗感染（2026-09-16 至 2026-09-20，共 5 天），辅以退热、补液等对症支持；继续氨氯地平 5mg 每日一次口服控制血压。治疗第 3 天体温降至正常，咳嗽减轻、咳痰减少。2026-09-21 复查血常规恢复正常，胸片示右下肺片状影较前吸收好转。
出院诊断：1. 社区获得性肺炎　2. 高血压 2 级
出院情况：患者无发热、无咳嗽咳痰，精神饮食可，大小便正常。查体：T 36.5℃，P 76 次/分，R 18 次/分，BP 128/78 mmHg，双肺呼吸音清、未闻及干湿性啰音。
出院医嘱：
1. 药物治疗：头孢克肟分散片 0.1g 每日二次口服，共 3 天；氨氯地平 5mg 每日一次口服，长期服用，监测血压。
2. 复诊安排：1 周后门诊复查胸片；若再次出现发热、咳嗽加重或胸痛，及时就诊。
3. 生活方式：戒烟，避免受凉，保证休息与营养。
4. 注意事项：出现气促、咯血或意识改变须立即就医。
医师签名：李××
```

## 三、要点

1. 入院情况是**摘要**，不全文复录入院记录。
2. 诊疗经过按时间顺序写主要干预、检查结果演变与疗效，与出院诊断前后呼应。
3. 出院诊断由主治医师及以上作出，与病历其他部分一致。
4. 出院医嘱具体到剂量、用法、疗程、复诊时间与就医指征，避免“按时服药”等空泛表述。
