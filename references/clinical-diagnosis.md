# 临床诊断与依据（按需读取）

本文件用于“诊断依据”“鉴别诊断”“分析这个患者”以及需要在病历中写诊断思路的请求。目标是提供可复核的工作诊断，而非替代医师作出最终诊断。

## 一、诊断分级

| 状态 | 使用条件 | 文书处理 |
|---|---|---|
| 医生已确认 | 医生在输入中明确给出初步、修正或出院诊断 | 可按相应文书规范写入正文 |
| 支持诊断 | 现有资料支持，但尚未经医生确认 | 仅放在诊断支持区，标注“现有资料支持” |
| 拟诊/待排除 | 有合理可能性，但关键证据不足或需排除重要疾病 | 仅放在诊断支持区，说明缺口和区分检查 |
| 资料不足 | 缺少决定性病史、查体、检查或时间信息 | 不给诊断结论，列出待补充项 |

不得将“支持诊断”或“拟诊/待排除”改写为最终诊断、出院诊断或已执行医嘱。

## 二、诊断依据写法

每项诊断依据只引用病例中已提供的事实，并尽可能写明时间、数值、单位、来源或变化趋势。

```
【诊断依据】
支持诊断：____（状态：医生已确认 / 现有资料支持）
1. 病史：____。
2. 查体：____。
3. 检查：____（检查时间：____）。
4. 动态变化：____。
不支持或仍需排除：____。
关键缺口与下一步：____。
```

避免“一定、完全排除、明确无误”等绝对表述。除非医生已确认，使用“目前考虑”“现有资料支持”“暂不支持”“仍需结合”。

## 三、鉴别诊断

围绕主问题优先列 2～4 项，不为凑数罗列。每项按以下格式写：

```
与____鉴别：支持点____；不支持点____；仍需通过____明确/排除。
```

需优先排除危及生命或会改变即时处置的疾病。若存在危急信号，先输出紧急评估提示，再写鉴别诊断。

## 四、诊断层级与治疗衔接

需要体现完整临床思路时，读取 [clinical-reasoning-treatment.md](clinical-reasoning-treatment.md)。主要诊断、并发症/严重程度、合并症/风险因素、补充诊断和待排问题应分别标注，避免把新增诊断、症状和既往病史混为同一层级。

补充诊断须说明新增证据、发现时间及其对当前方案的影响。诊疗计划应逐一对应主要问题，写明目标、处理方向、监测和调整条件；具体剂量、疗程和高风险治疗仍按指南总则核验。

## 五、指南库路由

需要诊断标准、检查路径、治疗原则或推荐级别时：

1. 先读取 [guidelines/README.md](guidelines/README.md)，按主问题定位专科文件。
2. 再读取对应专科摘要，仅提取与当前主问题有关的诊断或处理依据。
3. 涉及具体阈值、剂量、疗程、禁忌、相互作用或急危重处置时，按指南总则核验权威原文；无法核验则标注“版本待核实”并只给原则性建议。
4. 输出【指南依据】时写明指南名称、年份、来源状态和核验日期；不得仅写“按最新指南”。

## 六、与病历正文的边界

- 病历正文：仅放医生确认的诊断、已发生的诊疗事实和经医生采纳的规范表述。
- 诊断支持区：放支持诊断、鉴别诊断、证据链、待补充项和指南依据。
- 治疗建议：未被医生明确采纳时放在诊断支持区，不写成已下达医嘱。
