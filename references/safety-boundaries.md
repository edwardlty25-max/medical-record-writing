# 安全边界（允许 / 禁止）

本文件是 [SKILL.md](../SKILL.md) 第八节的展开版，适用于**任何输出**，包括正文之外的中间文件与口头回报。

## 一、允许 / 禁止对照

| 允许 | 禁止 |
|---|---|
| 把医生提供的口述、草稿、报告整理成规范病历正文 | 补造未提供的病史、查体、诊断、医嘱、签名或时间 |
| 使用医生已确认的诊断写入正文 | 把模型分析、拟诊或指南建议写成已发生的医疗行为 |
| 客观转述报告自带的异常标记或危急值标记 | 自行判定何为危急值，或据此给出个体化抢救指令 |
| 引述指南名称、年份、来源状态 | 声称“最新”而未核验；凭记忆写具体剂量、疗程、阈值 |
| 提示“请就该项咨询管床医生 / 尽快复核” | 给出供患者自行实施的处方、剂量或方案 |
| 按医院制度留出签名与时间位置 | 代签、伪造签名或时间 |

## 二、底线话术

- 材料不足时：**“以下为根据现有资料整理的草稿，缺项已标【待补充】，请核对后使用。”**
- 诊断不确定时：**“目前考虑……现有资料支持……仍需结合……”**
- 涉及具体用药时：**“具体剂量与疗程须核对权威原文、药品说明书及本院路径。”**
- 面向患者/家属时：**“本技能面向医务人员。建议携带资料尽快就医，以下为一般健康信息。”**

## 三、必须置顶的急危重信号

出现下列任一情况，**先提示立即临床评估**，再输出文书或其他内容：

- 生命体征：收缩压 <90 mmHg、心率 >130 或 <40 次/分、呼吸 >28 次/分、SpO₂ <90%、意识改变；
- 危急值：血糖 <2.8 或 >33.3 mmol/L、K⁺ <2.8 或 >6.5 mmol/L、Na⁺ <120 mmol/L 等；
- 临床综合征：休克、呼吸衰竭、急性肾损伤、肝性脑病、活动性出血、DKA/HHS、急性心肌损伤。

上述阈值用于**提示复核**，不替代本院的危急值报告制度与处置流程。

## 四、隐私

输入前去除姓名、住院号、身份证号、联系方式、住址等直接标识符；不要把未脱敏病历上传到云端模型。输出中非必要不复述标识符，示例数据一律虚构。

## 五、职责边界

本技能不代替医师诊断、处方、签名或医院审核；医院现行制度与有效法规优先于本捆绑摘要。发现材料前后矛盾时并列呈现，不自行合理化。
