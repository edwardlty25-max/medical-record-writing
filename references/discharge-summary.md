# 出院记录：书写逻辑与模板

> 依据：《河北省病历书写规范（2013年版）》（冀卫办医政〔2013〕30号），**本院现行制度优先**；标注「2023 补充/修订」的条目须与本院现行版本核对（见 [rules.md](rules.md)）。

书写时限：**出院后 24 小时内**完成。**出院诊断由主治医师及以上资质作出**，书写于**末页左侧**；一式两份，一份归档，一份交患者保存。自动出院（签字离院）须写明“患者/家属要求出院并签字”。

> 本页只讲**怎么写**；成文后请打开 [discharge-checklist.md](discharge-checklist.md) 逐项复核（易漏要素、常见缺陷、输出字段清单）。

## 一、书写逻辑（7 步链）

> 提炼自真实内科出院记录的共性结构（已去标识）。核心口诀：**答案在前，证据在后；每个变更都要有依据，每个未解决的问题都要有出口。**

| 步 | 环节 | 作用 | 写法要点 |
|---|---|---|---|
| ① | **基线**｜入院情况 | 给出院时对比的基准 | 主诉式开头（“患者因‘…’于 X 年 X 月 X 日入院”）→ 现病史摘要 → 与本次相关的既往史（逐个问题，含过敏史）→ 查体要点 → **入院前已有检查及结果**（附数值与单位） |
| ② | **定调**｜入院诊断 | 与首页、首程一致 | 按主次排序，不新增、不合并 |
| ③ | **立据**｜诊疗经过开篇 | 说明诊断是怎么来的 | “入院后结合（年龄性别、病史年限、症状特点、既往检查、查体），初步诊断同入院诊断” |
| ④ | **时间线**｜住院检查 | 让审阅者可逐条核验 | 按**日期**顺序列：日期 + 项目 + 关键结果（异常值附参考范围） |
| ⑤ | **演变**｜诊断变化 | 体现临床思维 | “辅助检查提示…，加用…，**补充诊断：1.__ 2.__**”；修正/补充须写**依据 + 发现时间 + 对治疗的影响** |
| ⑥ | **问题线**｜处理与决策 | 诊疗经过的正文 | 按**临床问题分段**：问题 → 依据 → 处理（通用名 + 剂量 + 途径 + 频次）→ 疗效与监测；**患者拒绝的检查、替代方案与沟通一并写明**；**住院期间有手术/介入者，手术相关一段独立写**（见第五节）；**会诊按时间点归位并写采纳情况**（见第四节） |
| ⑦ | **收口**｜小结与转归 | 回答“为什么可以出院” | 会诊整合 → 治疗小结 → 出院前复查（含关键阴性结果）→ 症状与病情转归 → 准予出院；**未解决问题写入复诊安排** |

### 三条线并行，不要只堆检验值

- **诊断线**：诊断 → 依据 → 演变（修正/补充）→ 出院诊断；
- **时间线**：入院前检查 → 住院各日期检查/操作 → 出院前复查；
- **问题线**：每个临床问题一段，讲清“为什么这样处理、效果如何、下一步怎么判断”。

### 七条硬技巧

1. **前后呼应**：出院诊断每一条，都能在诊疗经过中找到“何时、因何、由谁确认”；入院时的异常值，出院前应有复查对照。
2. **变更留痕**：诊断变更写“依据 + 时间 + 对治疗的影响”；治疗变更写“原因 + 目标 + 监测与复评条件”。
3. **会诊要转写**：不得照录会诊原文（尤其“贵科”“我科”等他科口吻），一律转成本科叙述——“会诊科室 + 意见 + 本科采纳情况”。
4. **未解决必须有出口**：患者拒绝的检查、尚未明确的诊断、待复查项目，都要进“出院医嘱—复诊安排”（建议做什么、何时复查、出现何情况须就诊）。
5. **阴性也要留证**：支撑“病情好转、准予出院”的关键阴性结果（核酸、抗原、培养、影像等）要写进出院前评估。
6. **数值三件套**：结果 + 单位 + 参考范围。
7. **用药四要素**：通用名 + 剂量 + 频次/途径 + 疗程或停用条件（如“5 天后停用”），并写监测项；不写商品名，不写“继续原治疗”。

## 二、模板

### A. 思考骨架（**仅用于组织内容，不得进入正文**）

```
出院记录

出院时间：____　入院日期：____　出院日期：____
姓名：____　性别：____　年龄：____　住院号：____

入院情况：主诉式开头 + 现病史摘要 + 与本次相关的既往史（含过敏史）+ 查体 + 入院前检查
入院诊断：按主次排序
诊疗经过：
　【诊断依据】年龄性别 + 病史年限 + 症状特点 + 既往检查 + 查体 → 初步诊断
　【住院检查】按日期：日期 + 项目 + 关键结果（异常值附参考范围）
　【诊断演变】新增证据 → 补充/修正诊断 + 依据 + 时间 + 对治疗的影响
　【上级医师意见】关键决策（查房/会诊）的意见、依据与本科采纳情况
　【问题导向处理】每个临床问题：依据 → 处理 → 疗效与监测（含拒绝与替代方案）
　【输血与不良反应】如已输血：品种、数量、输注时间、有无输血反应（含知情同意）
　【特殊情况】抢救 / 转入 ICU / 转科 / 非医嘱出院 / 转院 / 死亡衔接（无则写“无”）
　【会诊】按时间点就地归位，写成诊疗叙述的一部分，如"因胸痛，结合中医科会诊意见（考虑胸痹）加用××"
　　　　每条含：科室 + 意见要点 + 采纳情况（采纳写"已执行、疗效/复查结果"；未采纳或患者拒绝写"理由 + 替代方案 + 已告知 + 随访出口"）
　　　　✗ 反面写法："住院期间多学科会诊及落实情况：××科会诊……；××科会诊……"——清单式罗列，生硬、脱离诊疗逻辑
　【治疗小结】住院期间给予……等治疗
　【出院前评估】出院前复查 + 关键阴性结果
　【转归】症状与病情 → 准予出院 / 转院 / 自动出院
出院诊断：与入院诊断、补充诊断逐条对应
出院情况：症状 + 生命体征 + 查体 + 功能状态 + 饮食睡眠大小便 + 待办检查
出院医嘱：药物治疗（按维度分组）/ 复诊安排 / 生活方式 / 注意事项
医师签名：全名　日期：____
```

### B. 成文形态（**唯一可粘贴进 HIS 的版本**）

> 转换规则：**保留骨架的段落顺序，删除全部【】标签**，写成连续段落。骨架只用在你组织内容时；输出前逐条删除。

```
出院记录

出院时间：____　入院日期：____　出院日期：____
姓名：____　性别：____　年龄：____　住院号：____

入院情况：____（主诉式开头 + 现病史摘要 + 既往史 + 查体 + 入院前检查）
入院诊断：1. ____　2. ____
诊疗经过：____
（有手术/介入时按三段式：第 1 段术前评估 → 第 2 段手术/介入 → 第 3 段术后评估与出院前评估
 → 会诊（首选就地归位：术前会诊写术前段、术后会诊写术后段、住院后期会诊与补充诊断同段；
   确有多条且散落时，才在末尾用一句话说明"住院期间经××科会诊，已按会诊意见处理"）
 → 治疗小结与特殊情况（输血、抢救、转科等，无则写无）→ 转归）
（无手术时：第 1 段诊断依据 → 第 2 段住院检查按日期 → 第 3 段诊断演变与上级医师意见
 → 第 4 段按问题写处理与决策（含拒绝、替代方案、输血及输血反应）
 → 第 5 段会诊整合与特殊情况 → 第 6 段治疗小结、出院前评估与转归）
出院诊断：1. ____　2. ____
出院情况：____
出院医嘱：
1. 药物治疗：____（按治疗维度分组；通用名 + 剂量 + 频次/途径 + 疗程或停用条件 + 监测）
2. 复诊安排：____（时间、科室、项目、目的；未完成或患者拒绝的检查在此给出出口）
3. 生活方式：____（饮食、运动、休息、禁忌）
4. 注意事项：____（需及时就医的症状；联系方式）
医师签名：________（全名）　日期：____
```

### 取舍三原则（决定“写多少”）

1. **异常的、支撑诊断的、出院需对照的**检查：写全（结果 + 单位 + 参考范围）。
2. **同一指标多次检测**：写**趋势**（如 HGB 62 → 95 → 88 g/L），不逐次罗列全部项目。
3. **正常且不改变决策的同类结果**：合并成一句（“其余血常规、生化指标未见明显异常”）。

> 出院小结不是化验单复刻：全量数据留在辅助检查与病程记录里，出院记录只留**能改变判断的部分**。

## 三、有手术/介入时：检查与关键节点写在哪（资源位置表）

> 出院记录最容易乱的一段，就是检查结果堆在一起、说不清"哪一项支持诊断、哪一项证明有效"。
> 规则只有一条：**检查不按时间堆，按它在故事里的作用归位**——术前检查服务于"为什么诊断、为什么手术"，
> 术中描述服务于"做了什么"，术后复查服务于"是否有效、是否安全"。

### 位置对照表（必须背下来）

| 内容 | 写在哪个段落 | 具体位置 | 写法要求 | 不写在哪里 |
|---|---|---|---|---|
| **入院前检查**（外院/门诊） | 入院情况 | **段末**，标"入院前辅助检查" | 项目 + 数值 + 单位 + 参考范围；**院外检查必写机构名称、检查号、检查日期** | 不写入院诊断段；不写进诊疗经过 |
| **入院后术前检查**（支持手术指征、术前准备） | 诊疗经过 | **第 1 段（诊断依据/术前评估）** | 只留有决策价值的项目（心脏超声、造影前肾功能、凝血、感染筛查等）；异常值附参考范围 | 不与术后复查混在一句 |
| **术中情况** | 诊疗经过 | **第 2 段（手术段）** | 一句说明术式与大致经过，写明详见手术记录；不展开技术细节，避免与手术记录重复或出现出入 | 不写进辅助检查栏；不与术后复查混写 |
| **术后复查**（疗效 + 安全） | 诊疗经过 | **第 3 段（术后评估段）** | 写趋势与结论：术前 X → 术后 Y；含与本次手术相关的关键复查（血常规、肝肾功能与电解质、心肌损伤标志物、心电图、影像等） | 不写进「出院前评估」 |
| **住院期间新发现问题的检查** | 诊疗经过 | 独立成段（补充诊断） | 依据（项目 + 数值）+ 时间 + 对治疗的影响 | 不在出院诊断里首次出现 |
| **会诊相关检查** | 诊疗经过 | 会诊整合段 | 会诊科室 + 意见 + 本科采纳情况 | 不照抄会诊单 |
| **出院前复查** | 诊疗经过末段 **或** 出院前评估 | 紧接术后段之后 | 写本次出院所依据的关键结果（含关键阴性结果）；异常的写出院后复查计划 | 不重复罗列前几次全部数据 |
| **未完成/拒查项目** | 出院医嘱—复诊安排 | — | 写清建议项目、时间、何情况须就诊 | 不留在病程里没有出口 |
| **出院诊断** | 独立一段 | 与入院诊断、补充诊断逐条对应 | 术后病例写"经皮冠状动脉介入治疗后"等状态诊断 | 不与诊疗经过混写 |

### 三段式写法（有手术的出院记录专用骨架）

```
诊疗经过：
第 1 段 · 术前评估（为什么诊断、为什么手术）
  危险因素 + 症状特点 + 心电图/心肌损伤标志物 + 术前心脏超声/肾功能/凝血 → 诊断成立、具备手术指征
  若术前检查阴性：写明"术前检查未见手术禁忌"（一句话即可，不逐项罗列）
第 2 段 · 手术/介入（做了什么）
  日期 + 术式全称 + 一句经过（详见手术记录）+ 术中情况及并发症结论
  + 遗留问题与后续计划；不重复手术记录的技术细节
第 3 段 · 术后评估与出院前评估（是否有效、是否安全、能否出院）
  术后症状转归 + 切口与引流等局部情况 + 复查（术前 X → 术后 Y）
  + 出院前复查（关键阳性与阴性结果）→ 准予出院
```

### 四条硬规则

1. **术前检查只留"能改变决策的"**：心脏超声、肾功能、凝血、感染筛查等；常规血尿便、生化全量留入院记录，不搬进出院记录。
2. **术后复查必须回答两个问题**：治疗有效吗（症状 + 相关检查或影像）、安全吗（血常规、肝肾功能与电解质、局部情况、出血或感染征象）。
3. **同一指标术前术后对照写**，用箭头或"较前"表示趋势（如"高敏肌钙蛋白 I 0.08 → 0.02 μg/L"）；多次复查只写趋势，不逐次罗列。
4. **出院前复查是"准予出院"的证据**：正常要写（关键阴性结果），异常要写随访出口；未完成的项目（如动态心电图）进复诊安排。

> 完整范例见 examples/discharge-with-procedure-example.md（有手术的出院记录，含术前/术中/术后/出院前四层检查位置）。

## 四、会诊写在哪（不照搬会诊单，按时间点归位）

住院期间的会诊在病历里有自己的**会诊记录单**（申请科室、会诊科室、会诊时间、会诊医师意见与签名）——那份单据不需要在出院记录里重抄一遍。出院记录里要做的是**转写 + 归位 + 写采纳**。

### 三条原则

1. **转写成本科口吻**：删掉"贵科""我科""请协助诊治"等原文痕迹，写成"××科会诊考虑××，建议××，本科已采纳（或未采纳，理由××）"。
2. **按时间点归位**：会诊出现在诊疗经过的哪个阶段，就写进那一段——与术前评估同时发生→写术前段；与术后处理同时发生→写术后段；出院前新问题→写独立成段。
3. **必须写采纳情况**：采纳写"已采纳并执行××"；不采纳或患者拒绝写"未执行，理由××，替代方案××，已告知××"，并在出院医嘱—复诊安排留出口。

### 位置对照

| 会诊发生的时间点 | 写在哪个段落 | 典型科室 |
|---|---|---|
| 入院后、手术前（评估指征/能否耐受手术） | 诊疗经过**第 1 段（术前评估）** | 心外科、麻醉科、呼吸科、肾内科、内分泌科 |
| 手术当日或术后早期（处理并发症/合并症） | 诊疗经过**第 3 段（术后评估）** | 中医科、康复科、感染科、肾内科、营养科 |
| 住院后期新发现问题 | 诊疗经过**独立成段** | 肝病科、呼吸科、血液科、皮肤科 |
| 出院前一天（出院前评估） | 诊疗经过**末段（出院前评估）** | 任何科室 |
| 多条会诊 | **首选：各按时间点分写进对应段**（如术后处理句里"结合××科会诊意见加用××"）；只有当某条会诊无处安放时，才在诊疗经过末尾用一句话带过 | — |

### 一条会诊的转写句式

```
____科会诊（日期 时间）考虑____（诊断/评估），建议____（具体意见），
本科已采纳并于（日期）执行____（落实情况）；或：本科未采纳/患者拒绝____，
理由____，已改为____（替代方案），并告知____（风险与随访计划）。
```

### 三条反面写法

| 不合格 | 问题 |
|---|---|
| "住院期间请××科会诊，详见会诊单。" | 出院记录不能把结论推给会诊单，阅读者看不到采纳情况 |
| "会诊意见：建议完善肝胆胰脾超声、甲胎蛋白……" | 照抄会诊单原文，且未写患者拒绝与随访出口 |
| "××科会诊，建议继续目前治疗。" | 无会诊时间、无具体意见、无采纳结果，等于没写 |

> 多科会诊逐条写采纳情况，不得笼统写"按会诊意见处理"。会诊记录单本身的写法见 [progress-note.md](progress-note.md) 第六节与第十节。

**为什么不要另起"会诊落实情况"段**：出院记录的诊疗经过是一段**因果叙述**（为什么这样诊断 → 为什么这样治 → 效果如何）。会诊是决策的**依据之一**，写进它影响的那一步才自然：
"因胸痛，结合中医科会诊意见（考虑胸痹）加用中药汤剂"——读起来是诊疗；写成"住院期间多学科会诊及落实情况：中医科会诊……；康复科会诊……"——读起来是台账。
只在**会诊条数多且散落**、或**出院前集中会诊**而无处安放时，才用一句自然的总结（如"住院期间经中医科、康复科、肝病科会诊，相关意见已按上述执行"）。

## 五、围手术期整合（住院期间做过手术/介入时必写）

只要住院期间做过手术或有创操作，出院记录就要把这一段讲清楚——**但不必复述手术记录**（术式细节、器械、术中所见由手术记录承载）。我们要交代的是：为什么做、做了什么、术后怎么样、下一步怎么随访。

**围术期五要素**

| 要素 | 写法 | 常见硬伤 |
|---|---|---|
| ① 术前 | 指征（症状+检查依据）、术前讨论与上级意见、知情同意（须写"签署意见"） | 只写"同意手术"，无指征依据 |
| ② 术中 | 日期 + 术式全称 + 一句经过 + 详见手术记录 + 并发症结论 | 只写手术顺利；或与手术记录互相矛盾 |
| ③ 术后当日 | 术后首次病程要点：症状、生命体征、切口与引流、相关肢体末梢循环、复查项目 | 术后病程缺失 |
| ④ 术中遗留问题 | 未能一并处理的原因与后续计划（分期处理 / 保守治疗 / 复查评估） | 只字不提遗留问题 |
| ⑤ 出院前 | 切口或局部愈合情况、复查结果（血常规、肝肾功能与电解质、心肌损伤标志物等）、**出院带药核对**、复诊时间与危险信号宣教 | 无出院前评估；带药与病程不一致 |

**围术期专项提示**

- 使用**抗凝/抗血小板**者：写出有无出血征象（皮肤黏膜、牙龈、黑便、血尿、头晕头痛）与切口情况；出院医嘱写疗程、停用条件与出血时如何处理。
- **多科会诊**（中医科、康复科、肝病科等）：出院记录里按"会诊科室 + 意见 + 本科采纳情况"整合；患者拒绝的项目转入复诊安排。
- **术中遗留问题**与**分期处理计划**必须与病程记录一致，不能只在出院记录里首次出现。

## 六、出院带药核对（写"药物治疗"前先做这一步）

出院带药与原病历不一致，是最容易被家属和医保稽核发现的问题。落笔前逐条核对：

| 核对项 | 要求 |
|---|---|
| 药名 | 通用名一致；同一药在病程、医嘱单、出院记录里**写法必须完全相同**（不得一处写阿托伐他汀、另一处写普伐他汀） |
| 剂量 | 数值 + 单位一致（如 20 mg 不可写成 50 mg） |
| 频次 | 与医嘱执行记录一致（qd/bid 用中文写清"每日一次/每日二次"） |
| 疗程 | 写清长期服用或具体天数、停用条件 |
| 新增/停用 | 出院新开的药写出**开始时间与理由**；住院期间停用的药写出停用原因 |
| 滞后项 | 出院后仍需复查肝肾功能的药（他汀、抗结核药等）写明复查时间与项目 |
| 合并症用药 | 高血压、糖尿病等慢病用药一并列出，不漏长期用药 |

> 若原始材料中同一药出现两种写法或两个剂量，**不得自行取舍**：并列呈现并请医生确认（对应 [rules.md](rules.md) 的冲突处理原则）。

## 七、出院医嘱的四类要素

| 类别 | 必须写清 | 反例 |
|---|---|---|
| 药物治疗 | 通用名、剂量、频次/途径、疗程或停用条件、需监测的不良反应 | “继续原治疗”“按时服药” |
| 复诊安排 | 时间、科室、项目、目的、结果异常时如何调整 | “门诊随诊” |
| 生活方式 | 饮食、运动、休息、烟酒与其他禁忌 | “注意休息”（无具体要求） |
| 注意事项 | 需立即就医的症状、联系方式 | 缺项 |

## 八、自检

**机检**：`python scripts/validate_note.py <正文文件> --kind discharge`

| 规则码 | 判定 | 级别 |
|---|---|---|
| `discharge_sections_missing` | 缺 入院情况 / 入院诊断 / 诊疗经过 / 出院诊断 / 出院情况 / 出院医嘱 | ERROR |
| `skeleton_label_leak` | 正文残留【诊断依据】【转归】等骨架标签 | ERROR |

| `no_unsolved_closure` | 诊疗经过有拒绝 / 待查等未完成事项，但复诊安排无对应出口 | WARN |
| `consult_note_copied` | 正文含“贵科”“我科”等照录会诊痕迹 | WARN |
| `allergy_history_missing` | 未见过敏史记录 | WARN |

| `untreated_lesion_unstated` | 提到术中遗留问题（未能一并处理的病变或病灶），但未写理由或后续计划 | WARN |

**人工必查**：

- [ ] 入院诊断 / 补充诊断 / 出院诊断三者对应，新增项在诊疗经过均有依据与时间
- [ ] 诊疗经过能回答“为什么这样诊断、为什么这样治、效果如何、下一步”
- [ ] 出院医嘱四类齐全，且药物写全剂量、频次、疗程、监测
- [ ] 患者拒绝或未完成的检查，已在复诊安排中给出出口
- [ ] 会诊意见已转写，无他科口吻
- [ ] 全文部位、侧别、数值、日期一致
- [ ] 签名全名与日期齐全；电子病历打印后补手写签名
- [ ] 有手术/介入者：围术期五要素齐全，出院前切口或局部愈合情况已写
- [ ] 出院带药与病程记录、医嘱单逐条核对一致（药名、剂量、频次）
