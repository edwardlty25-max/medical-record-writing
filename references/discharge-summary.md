# 出院记录：书写逻辑、模板与自检
> **版本 v1.9.0（2026-09-16）**｜依据：《河北省病历书写规范（2013年版）》（冀卫办医政〔2013〕30号），**本院现行制度优先**；标注「2023 补充/修订」的条目来源待核验（见 [rules.md](rules.md) 的「来源与核验状态」）。

书写时限：**出院后 24 小时内**完成。**出院诊断由主治医师及以上资质作出**，书写于**末页左侧**；一式两份，一份归档，一份交患者保存。自动出院（签字离院）须写明“患者/家属要求出院并签字”。

## 一、书写逻辑（7 步链）

> 提炼自真实内科出院记录的共性结构（已去标识）。核心口诀：**答案在前，证据在后；每个变更都要有依据，每个未解决的问题都要有出口。**

| 步 | 环节 | 作用 | 写法要点 |
|---|---|---|---|
| ① | **基线**｜入院情况 | 给出院时对比的基准 | 主诉式开头（“患者因‘…’于 X 年 X 月 X 日入院”）→ 现病史摘要 → 与本次相关的既往史（逐个问题，含过敏史）→ 查体要点 → **入院前已有检查及结果**（附数值与单位） |
| ② | **定调**｜入院诊断 | 与首页、首程一致 | 按主次排序，不新增、不合并 |
| ③ | **立据**｜诊疗经过开篇 | 说明诊断是怎么来的 | “入院后结合（年龄性别、病史年限、症状特点、既往检查、查体），初步诊断同入院诊断” |
| ④ | **时间线**｜住院检查 | 让审阅者可逐条核验 | 按**日期**顺序列：日期 + 项目 + 关键结果（异常值附参考范围） |
| ⑤ | **演变**｜诊断变化 | 体现临床思维 | “辅助检查提示…，加用…，**补充诊断：1.__ 2.__**”；修正/补充须写**依据 + 发现时间 + 对治疗的影响** |
| ⑥ | **问题线**｜处理与决策 | 诊疗经过的正文 | 按**临床问题分段**：问题 → 依据 → 处理（通用名 + 剂量 + 途径 + 频次）→ 疗效与监测；**患者拒绝的检查、替代方案与沟通一并写明** |
| ⑦ | **收口**｜小结与转归 | 回答“为什么可以出院” | 会诊整合 → 治疗小结 → 出院前复查（含关键阴性结果）→ 症状与病情转归 → 准予出院；**未解决问题写入复诊安排** |

### 三条线并行，不要只堆检验值

- **诊断线**：诊断 → 依据 → 演变（修正/补充）→ 出院诊断；
- **时间线**：入院前检查 → 住院各日期检查/操作 → 出院前复查；
- **问题线**：每个临床问题一段，讲清“为什么这样处理、效果如何、下一步怎么判断”。

### 七条硬技巧

1. **前后呼应**：出院诊断每一条，都能在诊疗经过中找到“何时、因何、由谁确认”；入院时的异常值，出院前应有复查对照。
2. **变更留痕**：诊断变更写“依据 + 时间 + 对治疗的影响”；治疗变更写“原因 + 目标 + 监测与复评条件”。
3. **会诊要转写**：不得照录会诊原文（尤其“贵科”“我科”等他科口吻），一律转成本科叙述——“会诊科室 + 意见 + 本科采纳情况”。
4. **未解决必须有出口**：患者拒绝的检查、尚未明确的诊断、待复查项目，都要进“出院医嘱—复诊安排”（建议做什么、何时复查、出现何情况须就诊）。
5. **阴性也要留证**：支撑“病情好转、准予出院”的关键阴性结果（核酸、抗原、培养、影像等）要写进出院前评估。
6. **数值三件套**：结果 + 单位 + 参考范围。
7. **用药四要素**：通用名 + 剂量 + 频次/途径 + 疗程或停用条件（如“5 天后停用”），并写监测项；不写商品名，不写“继续原治疗”。

## 二、模板

### A. 思考骨架（**仅用于组织内容，不得进入正文**）

```
出院记录

出院时间：____　入院日期：____　出院日期：____
姓名：____　性别：____　年龄：____　住院号：____

入院情况：主诉式开头 + 现病史摘要 + 与本次相关的既往史（含过敏史）+ 查体 + 入院前检查
入院诊断：按主次排序
诊疗经过：
　【诊断依据】年龄性别 + 病史年限 + 症状特点 + 既往检查 + 查体 → 初步诊断
　【住院检查】按日期：日期 + 项目 + 关键结果（异常值附参考范围）
　【诊断演变】新增证据 → 补充/修正诊断 + 依据 + 时间 + 对治疗的影响
　【上级医师意见】关键决策（查房/会诊）的意见、依据与本科采纳情况
　【问题导向处理】每个临床问题：依据 → 处理 → 疗效与监测（含拒绝与替代方案）
　【输血与不良反应】如已输血：品种、数量、输注时间、有无输血反应（含知情同意）
　【特殊情况】抢救 / 转入 ICU / 转科 / 非医嘱出院 / 转院 / 死亡衔接（无则写“无”）
　【会诊整合】会诊科室 + 意见 + 本科采纳情况
　【治疗小结】住院期间给予……等治疗
　【出院前评估】出院前复查 + 关键阴性结果
　【转归】症状与病情 → 准予出院 / 转院 / 自动出院
出院诊断：与入院诊断、补充诊断逐条对应
出院情况：症状 + 生命体征 + 查体 + 功能状态 + 饮食睡眠大小便 + 待办检查
出院医嘱：药物治疗（按维度分组）/ 复诊安排 / 生活方式 / 注意事项
医师签名：全名　日期：____
```

### B. 成文形态（**唯一可粘贴进 HIS 的版本**）

> 转换规则：**保留骨架的段落顺序，删除全部【】标签**，写成连续段落。骨架只用在你组织内容时；输出前逐条删除。

```
出院记录

出院时间：____　入院日期：____　出院日期：____
姓名：____　性别：____　年龄：____　住院号：____

入院情况：____（主诉式开头 + 现病史摘要 + 既往史 + 查体 + 入院前检查）
入院诊断：1. ____　2. ____
诊疗经过：____
（第 1 段诊断依据 → 第 2 段住院检查按日期 → 第 3 段诊断演变、补充诊断与上级医师意见
 → 第 4 段按问题写处理与决策（含拒绝、替代方案、输血及输血反应）
 → 第 5 段会诊整合与特殊情况 → 第 6 段治疗小结、出院前评估与转归）
出院诊断：1. ____　2. ____
出院情况：____
出院医嘱：
1. 药物治疗：____（按治疗维度分组；通用名 + 剂量 + 频次/途径 + 疗程或停用条件 + 监测）
2. 复诊安排：____（时间、科室、项目、目的；未完成或患者拒绝的检查在此给出出口）
3. 生活方式：____（饮食、运动、休息、禁忌）
4. 注意事项：____（需及时就医的症状；联系方式）
医师签名：________（全名）　日期：____
```

### 取舍三原则（决定“写多少”）

1. **异常的、支撑诊断的、出院需对照的**检查：写全（结果 + 单位 + 参考范围）。
2. **同一指标多次检测**：写**趋势**（如 HGB 62 → 95 → 88 g/L），不逐次罗列全部项目。
3. **正常且不改变决策的同类结果**：合并成一句（“其余血常规、生化指标未见明显异常”）。

> 出院小结不是化验单复刻：全量数据留在辅助检查与病程记录里，出院记录只留**能改变判断的部分**。

## 三、出院医嘱的四类要素

| 类别 | 必须写清 | 反例 |
|---|---|---|
| 药物治疗 | 通用名、剂量、频次/途径、疗程或停用条件、需监测的不良反应 | “继续原治疗”“按时服药” |
| 复诊安排 | 时间、科室、项目、目的、结果异常时如何调整 | “门诊随诊” |
| 生活方式 | 饮食、运动、休息、烟酒与其他禁忌 | “注意休息”（无具体要求） |
| 注意事项 | 需立即就医的症状、联系方式 | 缺项 |

## 四、易漏要素（逐项确认）

| 要素 | 写在哪 | 必须写清 | 机检 |
|---|---|---|---|
| **过敏史** | 入院情况 | 药物、食物过敏史；无则写“无” | `allergy_history_missing` |
| **输血** | 诊疗经过 | 血制品品种、数量、输注时间、**有无输血反应**、知情同意 | `transfusion_reaction_unstated` |
| **上级医师意见** | 诊疗经过 | 关键决策（诊断变更、升级治疗、停药）的上级意见与采纳情况 | 人工 |
| **特殊情况** | 诊疗经过 | 抢救、转入 ICU、转科、非医嘱出院、转院、死亡衔接（无则写“无”） | 人工 |
| **关键阴性结果** | 出院前评估 | 支撑“病情好转、准予出院”的核酸/抗原/培养/影像阴性结果 | 人工 |
| **未解决问题出口** | 出院医嘱—复诊安排 | 患者拒绝或待查项目：建议做什么、何时复查、何情况须就诊 | `no_unsolved_closure` |

## 五、常见缺陷（真实病历高频出现）

| # | 缺陷 | 正确做法 | 机检 |
|---|---|---|---|
| 1 | 诊疗经过一整段、检验值堆砌，读完不知结论 | 按诊断线/时间线/问题线分段，每段有结论 | 人工 |
| 2 | 检验值只写数字，无单位、无参考范围 | 结果 + 单位 + 参考范围；多次检测写趋势 | 部分 |
| 3 | 会诊意见照录，含“贵科”“我科” | 转写为本科叙述：科室 + 意见 + 采纳情况 | `consult_note_copied` |
| 4 | 部位/侧别前后不一致 | 通篇核对；确有冲突时并列呈现并注明 | 人工 |
| 5 | 出院诊断与入院诊断、补充诊断不对应 | 逐条溯源：何时、因何确认 | 人工 |
| 6 | 患者拒绝或待查项目没有出口 | 写入复诊安排与注意事项 | `no_unsolved_closure` |
| 7 | 出院情况漏生命体征 | 至少写 T/P/R/BP | 人工 |
| 8 | 药物只写商品名或漏剂量/疗程 | 通用名 + 剂量 + 频次 + 疗程 + 监测 | 部分 |
| 9 | 时间写法混用（“上午 8 点”“8 时”） | 统一 24 小时制并尽量到分；采样时点写“（8:00）” | `time_12h`、`time_minute` |
| 10 | 自动出院无患者/家属意见记录 | 写明“患者/家属要求出院并签字” | 人工 |
| 11 | 缺必备段落（如漏“出院情况”） | 六大段齐全 | `discharge_sections_missing` |
| 12 | 骨架标签【】被粘进正文 | 只输出成文形态 | `skeleton_label_leak` |

## 六、自检

**机检**：`python scripts/validate_note.py <正文文件> --kind discharge`

| 规则码 | 判定 | 级别 |
|---|---|---|
| `discharge_sections_missing` | 缺 入院情况 / 入院诊断 / 诊疗经过 / 出院诊断 / 出院情况 / 出院医嘱 | ERROR |
| `skeleton_label_leak` | 正文残留【诊断依据】【转归】等骨架标签 | ERROR |
| `orders_categories_missing` | 出院医嘱四类（药物 / 复诊 / 生活方式 / 注意事项）不全 | WARN |
| `no_recheck_plan` | 出院医嘱无复查 / 复诊 / 随诊安排 | WARN |
| `no_unsolved_closure` | 诊疗经过有拒绝 / 待查等未完成事项，但复诊安排无对应出口 | WARN |
| `consult_note_copied` | 正文含“贵科”“我科”等照录会诊痕迹 | WARN |
| `allergy_history_missing` | 入院情况/既往史未见过敏史（出院、入院、首程适用） | WARN |
| `transfusion_reaction_unstated` | 记录了输血/输注血制品，但未写有无输血反应 | WARN |

**人工必查**：

- [ ] 入院诊断 / 补充诊断 / 出院诊断三者对应，新增项在诊疗经过均有依据与时间
- [ ] 诊疗经过能回答“为什么这样诊断、为什么这样治、效果如何、下一步”
- [ ] 出院医嘱四类齐全，且药物写全剂量、频次、疗程、监测
- [ ] 患者拒绝或未完成的检查，已在复诊安排中给出出口
- [ ] 会诊意见已转写，无他科口吻
- [ ] 全文部位、侧别、数值、日期一致
- [ ] 签名全名与日期齐全；电子病历打印后补手写签名
