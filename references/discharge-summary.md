# 出院记录模板（河北细则）

书写时限：**出院后 24 小时内**完成。**出院诊断由主治医师及以上资质作出**，书写于末页左侧；一式两份，一份归档，一份交患者保存。

## 模板

```
出院记录

入院日期：____  出院日期：____
姓名：____  性别：____  年龄：____  住院号：____

入院情况：
____（主诉 + 现病史摘要 + 入院查体要点 + 入院时辅助检查）

入院诊断：
1. ____
2. ____

诊疗经过：
____（住院期间主要诊疗措施：用药方案及调整、操作、检查结果演变、疗效与不良反应、
    病情变化及处理、上级医师查房意见；说明关键决策依据、诊断/补充诊断演变及未解决问题；前后呼应）

出院诊断：（主治医师及以上作出，书写于末页左侧）
1. ____
2. ____

出院情况：
____（出院时症状、体征、生命体征、功能状态、饮食睡眠大小便、后续检查待办）

出院医嘱：
1. 药物治疗：____（药物、剂量、用法、疗程、治疗目的及需监测的不良反应；无处方时明确说明）
2. 复诊安排：____（复诊时间、科室、指征）
3. 生活方式：____（饮食、运动、休息、禁忌）
4. 注意事项：____（出现何种症状需及时就医）

医师签名：________（全名）  日期：____
```

## 要点
- **入院情况**为摘要，不全文复录入院记录。
- **诊疗经过**按时间顺序，记录主要干预措施及效果，重要检查结果变化；与首页诊断**前后呼应**（协和逻辑）。
- **诊断演变**：说明初步、修正或补充诊断的依据及其对治疗选择的影响；未解决问题明确出院后处理路径。
- **出院诊断**按主次排序，由主治医师及以上作出，与病历其他部分一致。
- **出院医嘱**具体到药物剂量、用法、疗程、目的、监测和复诊触发条件，避免"按时服药"等空泛表述。
- 自动出院（签字离院）须写明"患者/家属要求出院并签字"，避免责任纠纷。
