# 出院记录：书写逻辑、模板与自检

书写时限：**出院后 24 小时内**完成。**出院诊断由主治医师及以上资质作出**，书写于**末页左侧**；一式两份，一份归档，一份交患者保存。自动出院（签字离院）须写明“患者/家属要求出院并签字”。

## 一、书写逻辑（7 步链）

> 提炼自真实内科出院记录的共性结构（已去标识）。核心口诀：**答案在前，证据在后；每个变更都要有依据，每个未解决的问题都要有出口。**

| 步 | 环节 | 作用 | 写法要点 |
|---|---|---|---|
| ① | **基线**｜入院情况 | 给出院时对比的基准 | “患者因‘…’于 X 年 X 月 X 日入院”→ 现病史摘要 → 与本次相关的既往史（逐个问题）→ 查体要点 → **入院前已有检查及结果**（附数值与单位） |
| ② | **定调**｜入院诊断 | 与首页、首程一致 | 按主次排序，不新增、不合并 |
| ③ | **立据**｜诊疗经过开篇 | 说明诊断是怎么来的 | “入院后结合（年龄性别、病史年限、症状特点、既往检查、查体），初步诊断同入院诊断” |
| ④ | **时间线**｜住院检查 | 让审阅者可逐条核验 | 按**日期**顺序列：日期 + 项目 + 关键结果（异常值附参考范围） |
| ⑤ | **演变**｜诊断变化 | 体现临床思维 | “辅助检查提示…，加用…，**补充诊断：1.__ 2.__**”；修正/补充须写**依据 + 发现时间 + 对治疗的影响** |
| ⑥ | **问题线**｜处理与决策 | 诊疗经过的正文 | 按**临床问题分段**：问题 → 依据 → 处理（药物/操作）→ 疗效与监测；**患者拒绝的检查、替代方案与沟通一并写明** |
| ⑦ | **收口**｜小结与转归 | 回答“为什么可以出院” | 会诊整合 → 治疗小结 → 出院前复查（含关键阴性结果）→ 症状与病情转归 → 准予出院；**未解决问题写入复诊安排** |

### 三条线并行，不要只堆检验值

- **诊断线**：诊断 → 依据 → 演变（修正/补充）→ 出院诊断；
- **时间线**：入院前检查 → 住院各日期检查/操作 → 出院前复查；
- **问题线**：每个临床问题一段，讲清“为什么这样处理、效果如何、下一步怎么判断”。

### 七条硬技巧

1. **前后呼应**：出院诊断每一条，都能在诊疗经过中找到“何时、因何、由谁确认”；入院时的异常值，出院前应有复查对照。
2. **变更留痕**：诊断变更写“依据 + 时间 + 对治疗的影响”；治疗变更写“原因 + 目标 + 监测与复评条件”。
3. **会诊要转写**：不得照录会诊原文（尤其“贵科”“我科”等他科口吻），一律转成本科叙述——“会诊科室 + 意见 + 本科采纳情况”。
4. **未解决必须有出口**：患者拒绝的检查、尚未明确的诊断、待复查项目，都要进“出院医嘱—复诊安排”（建议做什么、何时复查、出现何情况须就诊）。
5. **阴性也要留证**：支撑“病情好转、准予出院”的关键阴性结果（核酸、抗原、培养、影像等）要写进出院前评估。
6. **数值三件套**：结果 + 单位 + 参考范围；同一指标多次检测按日期排列，形成趋势。
7. **用药四要素**：通用名 + 剂量 + 频次/途径 + 疗程或停用条件（如“5 天后停用”），并写监测项；不写商品名，不写“继续原治疗”。

## 二、模板

> 括号内为填写提示，**输出时须全部删除**，不得出现在可粘贴正文中。

```
出院记录

出院时间：____（可按本院习惯置于文首）　入院日期：____　出院日期：____
姓名：____　性别：____　年龄：____　住院号：____

入院情况：患者因"____"于____年__月__日入院。既往：____（与本次相关的疾病、手术、用药、过敏史，逐个写）。
查体：T __℃　P __次/分　R __次/分　BP __/__mmHg；____（阳性体征 + 有意义的阴性体征）。
辅助检查：____（入院前或入院时；按"日期 + 项目 + 关键结果"，异常值附参考范围）。

入院诊断：1. ____　2. ____

诊疗经过：
【诊断依据】入院后结合____（年龄性别、病史年限、症状特点、既往检查、查体），初步诊断同入院诊断。
【住院检查】____（按日期顺序）。
【诊断演变】____（新增证据 → 补充/修正诊断：1. ____ 2. ____；依据、发现时间及对治疗的影响）。
【问题导向处理】
　1. ____（问题）：____（依据）→ 予____（通用名 + 剂量 + 途径 + 频次，或操作）→ ____（疗效与监测）。
　2. ____：……（含患者拒绝的检查、替代方案与沟通经过）
【会诊整合】____科：意见____；本科采纳____。
【治疗小结】住院期间给予____（治疗类别）等治疗。
【出院前评估】出院前复查____；____（关键阴性结果）。
【转归】患者症状____，病情____，准予出院/转院/自动出院。

出院诊断：（主治医师及以上作出，书写于末页左侧；按主次排序，与入院诊断、补充诊断逐条对应）
1. ____　2. ____

出院情况：____（症状、生命体征、查体、功能状态、饮食睡眠大小便、待办检查）

出院医嘱：
1. 药物治疗（按治疗维度分组，每组写通用名 + 剂量 + 频次 + 疗程 + 监测）：
　（1）____（维度）：____；
　（2）____：____；停用条件：____。
2. 复诊安排：____（时间、科室、项目、目的、据结果如何调整；患者拒绝或未完成的检查在此列出）
3. 生活方式：____（饮食、运动、休息、禁忌）
4. 注意事项：____（出现何种症状需及时就医；联系方式）

医师签名：________（全名）　日期：____
```

## 三、出院医嘱的四类要素

| 类别 | 必须写清 | 反例 |
|---|---|---|
| 药物治疗 | 通用名、剂量、频次/途径、疗程或停用条件、需监测的不良反应 | “继续原治疗”“按时服药” |
| 复诊安排 | 时间、科室、项目、目的、结果异常时如何调整 | “门诊随诊” |
| 生活方式 | 饮食、运动、休息、烟酒与其他禁忌 | “注意休息”（无具体要求） |
| 注意事项 | 需立即就医的症状、联系方式 | 缺项 |

## 四、常见缺陷（真实病历高频出现）

| # | 缺陷 | 正确做法 |
|---|---|---|
| 1 | 诊疗经过一整段、检验值堆砌，读完不知道结论 | 按诊断线/时间线/问题线分段，每段有结论 |
| 2 | 检验值只写数字，无单位、无参考范围 | 结果 + 单位 + 参考范围；多次检测按日期排 |
| 3 | 会诊意见照录，含“贵科”“我科” | 转写为本科叙述：科室 + 意见 + 采纳情况 |
| 4 | 部位/侧别前后不一致（影像与会诊、入院与出院） | 通篇核对；确有冲突时并列呈现并注明 |
| 5 | 出院诊断与入院诊断、补充诊断不对应 | 逐条溯源：何时、因何确认 |
| 6 | 患者拒绝或待查项目没有出口 | 写入复诊安排与注意事项 |
| 7 | 出院情况漏生命体征 | 至少写 T/P/R/BP |
| 8 | 药物只写商品名或漏剂量/疗程 | 通用名 + 剂量 + 频次 + 疗程 + 监测 |
| 9 | 时间写法混用（“上午 8 点”“8 时”） | 统一 24 小时制并尽量到分；采样时点写作“（8:00）” |
| 10 | 自动出院无患者/家属意见记录 | 写明“患者/家属要求出院并签字” |

## 五、自检

**机检**：`python scripts/validate_note.py <正文文件> --kind discharge [--admit "<入院时间>"]`
**人工必查**：

- [ ] 入院诊断 / 补充诊断 / 出院诊断三者对应，新增项在诊疗经过均有依据与时间
- [ ] 诊疗经过能回答“为什么这样诊断、为什么这样治、效果如何、下一步”
- [ ] 出院医嘱四类齐全（药物 / 复诊 / 生活方式 / 注意事项）
- [ ] 患者拒绝或未完成的检查，已在复诊安排中给出出口
- [ ] 会诊意见已转写，无他科口吻
- [ ] 全文部位、侧别、数值、日期一致
- [ ] 签名全名与日期齐全；电子病历打印后补手写签名
