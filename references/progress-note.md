# 病程记录模板（河北频率 + 协和结构）

## 一、日常病程记录 —— 频率（2023 修订）

| 患者类型 | 频率 |
|---|---|
| 病危 | ≥1 次/日，病情变化**随时**记录，记录到分 |
| 病重且稳定 | ≥1 次/**2 日** |
| 普通且稳定 | ≥1 次/**3 日** |
| 新入院 | 连续记录 **3 天** |
| 出院患者 | 出院前一天须有上级医师查房并记录；自动出院须有当天病程记录并含患者/家属意见及签字 |

## 二、日常病程记录 —— 一段话整合式（客观输入 → 智能输出）

将协和 6 段式内容压缩为**一段通顺的病程文字**。实际使用时明确分工：

**输入（客观条件 —— 医生提供/粘贴，skill 原样整合）：**
1. **一般情况**：神志、体位、症状演变、新发症状、出入量、体重变化、重要治疗及剂量疗程；
2. **查体**：当天生命体征、重点查体、阳性体征复核；
3. **辅助检查**：新结果（按常规/感染免疫/影像顺序，含重要正常指标与有意义的异常）；
4. **会诊意见**：如有（整理浓缩而非照抄）。

**输出（智能部分 —— 由 skill 生成，必不可少）：**
- **分析判断**：病情好转/加重/平稳的判断、诊断是否调整、治疗反应评估、医嘱变更理由；
- **诊疗计划**：下一步检查与治疗（可引用指南及版本）；
- **医患沟通**：向患者及家属告知的内容与家属意见。

**一段话模板（连续叙述、不编号分段；每个逻辑组独立成行，便于阅读）：**

```
____年__月__日 __:__
患者____（神志、体位、主要症状及演变、新发症状、出入量、体重变化），____（重要治疗及剂量）。
查体：____（生命体征、重点查体、阳性体征复核）。
辅助检查：____（新结果）。
会诊意见：____（如有）。
综合分析，____（病情好转/加重/平稳判断，诊断是否调整，治疗反应及医嘱变更理由），下一步诊疗计划：____（检查与治疗，可引用指南）。
已与患者及家属沟通____（告知内容），家属表示____（意见）。
医师签名：________
```

**要求**：重病/病情恶化当日必记；不得只记"病情平稳"而无具体内容；记录**选择检查和治疗方案的依据**。复杂病人（多系统受累）可展开为 **system-based（按系统）** 书写，默认输出仍为一段话。

## 三、上级医师查房记录

时限（单项否决相关）：新入院危重 **24h**、主治首次 **48h**、主任/副高首次 **72h**。频率：主治病程记录每周≥2 次；主任（副主任）每周≥1 次。

```
____年__月__日 __:__    ____主任医师查房
____（病情汇报、上级医师查体要点）
____（上级医师分析：诊断是否修正、下一步检查与治疗意见）
____（对下级医师的指示）
（记录医师签名、上级医师签名）
```

**主体是上级医师对病情的分析及诊疗安排**，而非复述下级汇报。

## 四、交接班记录

```
交接班记录（交班）

患者姓名：____  床号：____  住院号：____
入院日期：____  交班日期：____
目前病情及诊治经过：____
本班次发生的情况及处理：____
尚待解决的问题：____（需下一班重点关注）
交班医师签名：________（全名）
```

```
交接班记录（接班）

接班日期：____
接班时病情及查体：____
接班时需处理的问题及计划：____
接班医师签名：________（全名）
```

交接班记录在交/接班后 **24 小时内**完成。

## 五、抢救记录

抢救结束 **6 小时内**据实补记，注明抢救开始与结束时间、补记时间。

```
抢救记录

患者姓名：____  住院号：____
抢救开始时间：____  抢救结束时间：____
病情变化及抢救经过：____（逐时记录生命体征、用药、操作、心肺复苏细节）
抢救结果：____（成功 / 无效宣告死亡）
参与抢救人员：____
记录时间（补记时间）：____
记录医师签名：________（全名）
```

若患者死亡，与死亡记录衔接。
