# 病程记录模板（原则与模板见一页版，本页为展开说明）

> **只要原则和模板？** 先看 [progress-and-first-note-principles.md](progress-and-first-note-principles.md)（一页版：五条总原则 + 首程/病程/术前小结/术后病程/查房模板 + 句式 + 常见错）。本页是展开说明，按需查。
> 依据：《河北省病历书写规范（2013年版）》（冀卫办医政〔2013〕30号），**本院现行制度优先**；标注「2023 补充/修订」的条目须与本院现行版本核对（见 [rules.md](rules.md)）。

## 书写要点

1. **分工固定**：客观输入（一般情况、查体、辅助检查、会诊意见）**原样整合**；智能部分（分析判断、诊疗计划、医患沟通）由本技能补足——缺了这三项，病程就是流水账。
2. **结构二选一**：复杂病人（多系统受累）按**系统（system-based）**书写，力求不重不漏；简单病人围绕主问题按 **problem-based / S-O-A-P**（事实 → 评估 → 处理 → 复评）书写。
3. **上级查房记录的主体是上级医师的分析与安排**，不是复述下级汇报；主治每周 ≥2 次、主任/副主任每周 ≥1 次。
4. **会诊意见整理浓缩而非照抄**（照抄"贵科/我科"会被机检标出）；并且**会诊后必须写采纳情况**——"会诊科室 + 意见 + 本科采纳/不采纳及理由"三件套。会诊建议未执行（如患者拒绝进一步检查）时，拒绝一事须单独记录。
5. **病情变化必记**：重病或病情恶化当日必记；不得只写"病情平稳""继续原治疗"，必须写**选择检查与治疗方案的依据、目标及复评条件**。
6. **诊断变更留痕**：出现**修正诊断 / 补充诊断**时，必须写清五要素——**诊断名称 + 依据（具体检查、数值与时间）+ 对治疗的影响 + 书写者资质 + 签名日期**（见第九节）。
7. **患者拒绝必留痕**：写明**建议内容 + 拒绝理由 + 已告知的风险与替代方案 + 患者及家属意见**，并在出院医嘱—复诊安排留下出口（见第十节）。
8. **围手术期必记**：有手术或介入操作的病例，术后当日须有**首次术后病程记录**，并按术后第 1、2、3 天连续记录（见第八节），不得以"手术顺利、继续原治疗"带过。
9. **时间**：记录到分，与体温单、医嘱、检验报告时间一致。

## 模板（按文书类型）

### 一、日常病程记录 —— 频率（2023 修订【来源待核验】）

| 患者类型 | 频率 |
|---|---|
| 病危 | ≥1 次/日，病情变化**随时**记录，记录到分 |
| 病重且稳定 | ≥1 次/**2 日** |
| 普通且稳定 | ≥1 次/**3 日** |
| 新入院 | 连续记录 **3 天** |
| 出院患者 | 出院前一天须有上级医师查房并记录；自动出院须有当天病程记录并含患者/家属意见及签字 |

### 二、日常病程记录 —— 一段话整合式（客观输入 → 智能输出）

将协和 6 段式内容压缩为**一段通顺的病程文字**。实际使用时明确分工：

**输入（客观条件 —— 医生提供/粘贴，skill 原样整合）：**
1. **一般情况**：神志、体位、症状演变、新发症状、出入量、体重变化、重要治疗及剂量疗程；
2. **查体**：当天生命体征、重点查体、阳性体征复核；
3. **辅助检查**：新结果（按常规/感染免疫/影像顺序，含重要正常指标与有意义的异常）；
4. **会诊意见**：如有（整理浓缩而非照抄）。

**输出（智能部分 —— 由 skill 生成，必不可少）：**
- **分析判断**：病情好转/加重/平稳的判断、诊断是否调整、治疗反应评估、医嘱变更理由；
- **诊疗计划**：下一步检查与治疗（可引用指南及版本）；
- **医患沟通**：向患者及家属告知的内容与家属意见。

**一段话模板（连续叙述、不编号分段；每个逻辑组独立成行，便于阅读）：**

```
____年__月__日 __:__
患者____（神志、体位、主要症状及演变、新发症状、出入量、体重变化），____（重要治疗及剂量）。
查体：____（生命体征、重点查体、阳性体征复核）。
辅助检查：____（新结果）。
会诊意见：____（如有）。
围绕问题____，综合分析____（新事实如何支持/削弱原判断，病情好转/加重判断，诊断或补充诊断是否调整，治疗反应及变更理由），下一步诊疗计划：____（治疗目标、具体处理或待确认项、监测指标、调整/升级条件，可引用指南）。
已与患者及家属沟通____（告知内容），家属表示____（意见）。
医师签名：________
```

**住院期间每天必须交代清楚的 9 项数据（缺哪项就在成稿里标出来）**

| # | 数据元素 | 写法要求 | 常见遗漏 |
|---|---|---|---|
| 1 | 症状演变 | 与**昨日/术前**对比，不写"无变化" | 只写现状，无对比 |
| 2 | 生命体征 | T/P/R/BP 具体数值 | 抄前一天的数值 |
| 3 | 重点查体 | 阳性体征**复核** + 与本次问题相关的阴性体征 | 只写"查体同前" |
| 4 | 新检验/检查 | 项目 + 数值 + 单位 + 参考范围；含**有意义的正常结果** | 只报异常值 |
| 5 | 治疗与医嘱变更 | 通用名 + 剂量 + 途径 + 频次；**变更必须写理由** | 只写"调整用药" |
| 6 | 操作/手术当日要点 | 见第七节（术前小结）、第八节（术后六要素） | 手术当日只写"手术顺利" |
| 7 | 会诊意见 | 科室 + 时间 + 意见 + **采纳情况**（就地归位） | 只写"已请××科会诊" |
| 8 | 分析与计划 | 判断好转/加重/平稳的**依据**、诊断是否调整、下一步与复评条件 | 写"继续原治疗" |
| 9 | 医患沟通 | 告知内容 + 患者/家属意见；**拒绝**要写六要素 | 只写"已告知" |

**要求**：重病/病情恶化当日必记；不得只记"病情平稳"或"继续原治疗"而无具体内容；记录**选择检查和治疗方案的依据、目标及复评条件**。复杂病人（多系统受累）可展开为 **system-based（按系统）** 书写；简单病人围绕主问题按"事实→评估→处理→复评"书写。

**自然句式库**（照真实病历的口气写，不要写成台账）

| 场景 | 推荐句式 |
|---|---|
| 症状好转 | "患者未诉胸闷、胸痛，较昨日减轻" |
| 症状再发 | "昨夜再诉胸痛，予硝酸甘油静滴后缓解" |
| 检查结果支持判断 | "结合胸部 CT 示右肺上叶结节，考虑……" |
| 诊断变更 | "结合××检查结果，修正/补充诊断为××"（见第九节五要素） |
| 会诊影响决策 | "因胸痛，结合中医科会诊意见（考虑胸痹）加用中药汤剂" |
| 患者拒绝 | "建议××检查，患者因××拒绝，已告知××，改为××" |
| 计划与条件 | "继续××治疗；若出现××，则改为××" |

### 三、上级医师查房记录

时限（单项否决相关）：新入院危重 **24h**、主治首次 **48h**、主任/副高首次 **72h**。频率：主治病程记录每周≥2 次；主任（副主任）每周≥1 次。

```
____年__月__日 __:__    ____主任医师查房
____（经治医师简要汇报当日情况 + 上级医师查体要点）
____（上级医师分析：按"依据 → 判断 → 决策"写——依据哪项新事实，判断诊断是否修正、
　　治疗是否有效，为什么这样调整）
____（上级医师对下一步检查与治疗的具体意见，含停用/改用的条件）
____（对下级医师的指示与需落实的事项；复评时间点）
（记录医师签名、上级医师签名）
```

**主体是上级医师对病情的分析及诊疗安排**，而非复述下级汇报。三条硬要求：

1. **写"依据 → 判断 → 决策"**，不写"××主任查房后指示继续观察"。真实病历里的写法：
   "结合胸部 CT 示右肺上叶结节，考虑肺结节，建议定期复查胸部 CT、必要时胸外科随诊"——
   一句话里同时含依据、判断、决策与去向。
2. **每次查房都要有增量**：上级意见要与前一次不同（新检查、新调整、新计划），否则写明"维持原方案，××条件不变"。
3. **落实要留痕**：上级提出调整后，在当日或次日的病程中写"已按查房意见执行××"，形成闭环。

### 五、抢救记录

```

患者姓名：____  住院号：____
抢救开始时间：____  抢救结束时间：____
病情变化及抢救经过：____（逐时记录生命体征、用药、操作、心肺复苏细节）
抢救结果：____（成功 / 无效宣告死亡）
参与抢救人员：____
记录时间（补记时间）：____
记录医师签名：________（全名）
```

若患者死亡，与死亡记录衔接。

### 六、会诊记录

```

申请科室：____  会诊科室：____  会诊时间：____
会诊意见：
____（会诊医师对病情的分析、诊断意见、处理建议）
会诊医师签名：________（全名）
记录医师签名：________（全名）
```

### 七、术前小结 / 术前病程记录

**定位**：只写**我们这边负责的四件事**——为什么做（指征）、准备到什么程度、有什么风险、患者是否同意。**术式怎么做、用了什么器械、术中看到什么，属于手术记录，由手术医师书写，我们不写也不转抄。**

```
____年__月__日 __:__　术前小结 / 术前病程记录
患者____（当前症状较入院时的变化、生命体征、与本次操作相关的查体）。
术前诊断：1. ____　2. ____（与首程一致；有修正的写修正诊断及依据）
手术指征：____（症状特点 + 检查依据 + 功能状态；不做的后果）。
拟行手术/操作：____（名称 + 部位/侧别，一句写清，不展开术式细节）。
术前准备：____（术前检查结果是否达标、需要纠正的异常；抗凝/抗血小板药物是否停用或如何衔接；
禁食禁水、皮肤准备、备血、过敏史与肾功能核对）。
手术风险：____（出血、感染、麻醉风险、基础病加重等主要风险；对应防范措施）。
替代方案：____（药物保守治疗、其他方式、不手术的后果）。
上级医师意见：____（××医师查房同意手术，指示××）。
知情同意：____（已告知必要性、风险与替代方案，患者签署意见为"同意手术"，时间____；家属____）。
医师签名：________
```

**要点**：① 核心是**指征 + 准备 + 风险 + 同意**四件事，不是复述入院记录；② 术前检查正常也要写"某某检查未见手术禁忌"；③ 抗凝/抗血小板是否停用、如何衔接必须写明；④ 同意要写"签署意见"，只有签名不合格。

### 八、术后首次病程记录（术后我们接着写）

**定位**：手术记录由手术医师写；我们写**术后患者的反应、我们负责的观察与处置、下一步诊疗**。写"详见手术记录"即可，不重复手术经过。

```
____年__月__日 __:__
患者于____年__月__日行____（手术/操作名称），经过及术中所见详见手术记录。
术后患者____（神志、症状：疼痛/胸闷/心悸/恶心/呼吸困难等有无、饮食大小便、出入量）。
查体：T ____℃  P ____次/分  R ____次/分  BP ____/____mmHg；____（切口/引流管/敷料情况：
有无渗血、渗液、红肿、压痛；相关肢体或部位的感觉、活动、末梢循环与术前对比）；____（心肺腹等其他系统）。
辅助检查：____（术后复查项目：血常规、肝肾功能与电解质、心肌损伤标志物、心电图、影像等，
结果 + 单位 + 参考范围）。
用药：____（通用名 + 剂量 + 途径 + 频次 + 疗程；围术期相关药物写清用法与停用条件）。
综合分析：____（手术目的是否达到、术后变化说明什么、有无并发症迹象、是否需要调整方案）。
下一步诊疗计划：____（体位与活动、饮食、监测项目与频次、复查项目与时间、用药调整、
切口与管路护理、出现何种情况需立即处理）。
已向患者及家属告知术后注意事项及可能的风险，表示____。
医师签名：________
```

**术后第 1、2、3 天各记一次**，六要素：① 症状转归（与术前对照）② 生命体征 ③ 手术部位与引流（渗血、红肿、疼痛、末梢循环）④ 复查结果（术前 X → 术后 Y）⑤ 用药与调整 ⑥ 评估与下一步。

**两条我们自己的责任**

- **围术期用药观察**：抗凝/抗血小板治疗期间记录有无皮肤黏膜出血、牙龈出血、黑便、血尿、头晕头痛；按医嘱调整并写理由。
- **他科会诊**（中医科、康复科、肝病科等）按"科室 + 意见 + 本科采纳情况"写进当日病程，不能停在会诊单上。

### 九、修正诊断 / 补充诊断记录

一次完整的诊断变更记录包含**五要素**，缺一即视为留痕不全：

```text
____年__月__日 __:__　修正诊断 / 补充诊断记录
患者____（当日症状、体征）。
辅助检查：____（新证据：项目 + 数值 + 单位 + 参考范围 + 报告时间/机构名称与检查号，如为院外）。
诊断分析：原考虑____，现有资料支持____，不支持原诊断之处在于____，
故____（修正/补充）诊断为____（若涉及分级/分期、并发症、合并症，一并写明）。
对治疗的影响：____（用药、操作、监测或随访计划的相应调整）。
已向患者及家属告知____（诊断变更内容与理由），表示____。
记录医师签名：________（全名，主治医师及以上）　日期：____
```

**要点**

- 修正/补充诊断由**主治医师及以上**医师书写并签名、注明日期；住院期间的变更要在**末页诊断区**同步体现（初步 → 修正/补充 → 出院诊断）。
- **不在病程中留痕、只在出院记录里出现的新诊断**，属常见硬伤；反之，病程中提出的诊断也必须在出院诊断中体现或说明转归。

### 十、患者拒绝检查或治疗记录

```text
____年__月__日 __:__
患者____（当前症状、体征与关键检查结果）。
根据____（病情与依据），建议____（检查/治疗项目、目的与预期获益），
替代方案为____（其他检查或治疗方式及其局限）。
已向患者及家属详细告知上述建议的必要性、预期获益、可能风险以及拒绝的后果（包括____），
患者/家属因____（理由）拒绝____（具体项目），要求____（继续当前治疗 / 自动出院 / 观察）。
已告知拒绝可能造成____，患者及家属表示理解并坚持上述意见（必要时请其签字为证）。
下一步：____（替代方案、加强监测的项目与频次；出现何种症状须立即就诊；
未完成项目的复诊安排与时间）。
医师签名：________（全名）
```

**要点**：拒绝不等于免责——必须写"建议什么、为什么建议、拒绝什么、理由、告知了什么风险、替代方案是什么、后续如何监测、何时复诊"。自动出院另按 [discharge-summary.md](discharge-summary.md) 要求写明"患者/家属要求出院并签字"。

### 十一、多科会诊意见整理与采纳

| 写法 | 合格 | 不合格 |
|---|---|---|
| 表述 | 会诊科室 + 会诊时间 + 意见要点 + **本科采纳情况** | 照抄会诊单原文；只写"已请××科会诊" |
| 示例 | "中医科会诊（2026-09-12 17:50）考虑胸痹，建议中药汤剂与耳穴治疗，本科已采纳并于当日开始执行" | "请中医科会诊，建议中药治疗。" |
| 采纳/不采纳 | 不采纳须写理由与替代方案 | 会诊意见提出后病程中无下文 |
| 多项建议 | 逐条写采纳情况（执行 / 暂不执行 + 原因 / 患者拒绝） | 笼统写"按会诊意见处理" |

**出院记录中的会诊：就地归位，不要清单式罗列**

出院记录不重抄会诊单，也**不建议**另起"住院期间多学科会诊及落实情况：××科……；××科……"这类清单——它切断了诊疗叙述的因果链，读起来是台账而不是病历。首选把会诊写进它影响的那一步：

```
✗ 生硬（清单式）
住院期间多学科会诊及落实情况：2026-09-10 17:50 中医科会诊考虑胸痹，建议中药汤剂口服及耳穴
治疗，本科已采纳并于当日开始执行；2026-09-11 康复科会诊建议予物理治疗，本科已采纳并于当日
开始执行。

✓ 自然（就地归位）
2026-09-10 17:50 因胸痛，结合中医科会诊意见（考虑胸痹）加用中药汤剂口服及耳穴治疗；
2026-09-11 结合康复科会诊意见加用物理治疗改善局部循环、缓解疼痛，患者症状逐步缓解。
```

只有当会诊条数多、散落各处，或出院前集中会诊而无处安放时，才在诊疗经过末尾用**一句话**自然带过（如"住院期间经中医科、康复科、肝病科会诊，相关意见已按上述执行"），仍不写成逐条台账。下面给出三条会诊就地归位的完整示例（虚构）：

```
住院期间多学科会诊意见及落实情况：2026-09-10 17:50 中医科会诊考虑胸痹，建议中药汤剂口服
及耳穴治疗，本科已采纳并于当日开始执行；2026-09-11 10:20 康复科会诊建议予物理治疗改善局部
循环、缓解疼痛，本科已采纳并于当日开始执行；2026-09-16 08:30 肝病科会诊考虑酒精性肝损伤，
建议予多烯磷脂酰胆碱胶囊保肝治疗并完善肝胆胰脾超声、甲胎蛋白及肝弹性检查，本科已采纳保肝
治疗方案，治疗 3 天后复查丙氨酸转氨酶由 86 U/L 降至 48 U/L，患者拒绝进一步完善检查，已告知
可能风险及随访要点，相关项目已列入出院后复诊安排。
```

**要点**：采纳的要写"落到哪一步"（开始执行时间、治疗反应、复查结果）；未采纳或患者拒绝的要写"理由 + 替代方案 + 已告知 + 随访出口"。

## 自检

- 机检：`python scripts/validate_note.py <正文文件> --kind progress`（查房用 `--kind rounds-attending`、抢救用 `--kind rescue`；术后病程可加 `--kind progress` 并配合 `--admit` 勾稽时限）
  机检可检出：术后观察要素缺失（切口或引流、局部情况、复查项）、修正或补充诊断未写依据与时间、会诊意见无采纳情况、拒绝记录无告知与替代方案、时间未到分等。
- 人工：客观/智能两部分是否齐全；频率是否达标；分析结论是否有据；沟通记录是否落实；
  **诊断变更五要素、拒绝记录六要素、会诊三件套、术后三天连续记录**是否落实；
  **术前小结**是否含指征 + 准备 + 风险 + 同意四件事；**上级查房**是否有增量与落实。
