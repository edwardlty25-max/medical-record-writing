# 示范病例式临床推理与治疗计划（按需读取）

本文件用于首程、日常病程、出院记录中的诊断层级、补充诊断、治疗方向和决策逻辑。它借鉴公开可核验资料中“按临床实践顺序呈现入院至出院文书，并分析病情与检查变化”的组织方法；不复刻任何示范病历原文。

参考边界：参考《临床示范病历及思维解析》（ISBN 9787313236869，上海交通大学出版社）的公开书目信息与组织思路，仅吸收病例链和分析框架，不使用或复现书中病例文本。

## 一、病例主线

围绕一个随时间演变的主问题书写，而非堆砌检查和医嘱。每次记录回答：

1. 当前最重要的临床问题是什么？
2. 有哪些新事实支持、削弱或改变原判断？
3. 主要诊断、并发症、合并症和待排问题分别是什么？
4. 本次处理针对哪个问题，目标是什么？
5. 用什么指标判断治疗有效、何时调整或升级？

## 二、诊断层级与补充诊断

| 层级 | 内容 | 书写规则 |
|---|---|---|
| 主要诊断 | 当前住院的核心疾病或综合征 | 位于诊断首位，写明依据 |
| 并发症/严重程度 | 由主要疾病引起且影响处理或预后的问题 | 与主要诊断建立因果或严重度关系 |
| 合并症/风险因素 | 影响治疗选择、监测或预后的既往疾病、过敏、器官功能等 | 写明其对当前方案的影响 |
| 补充诊断 | 住院中经新病史、查体、检查或会诊确认的新增重要诊断 | 记录发现时间、依据、对方案的改变及确认医师要求 |
| 待排问题 | 尚不能确认但会改变即时处置的疾病 | 放诊断支持区，写清区分检查，不替代正式诊断 |

补充诊断不是为增加诊断数量而设。只有新信息确认且会影响管理时才添加；诊断名称、确认时间和资质要求以医院制度为准。

## 三、治疗计划六要素

对每个主要问题按以下顺序组织：

1. **目标与优先级**：稳定生命体征、控制病因、缓解症状、纠正并发症或降低风险。
2. **病因/靶向处理**：说明适应证和针对的问题；诊断未确认时只写评估或检查路径。
3. **对症与支持治疗**：补液、氧疗、营养、镇痛、止吐等须写明目的和观察点。
4. **并发症防治与安全核对**：过敏、肝肾功能、相互作用、出血/感染/血栓等风险及预防策略。
5. **监测、调整和升级条件**：复查项目、时机、有效标准、无效/恶化时的调整、会诊或转上级处理条件。
6. **沟通与共同决策**：告知诊断不确定性、方案收益风险、替代选择和患者/家属意见。

## 四、具体治疗的最小表达

仅在医生已提供且来源/适用条件可核验时，使用以下完整表达：

```
针对____，拟/已予____（通用名，剂量、给药途径、频次），起始于____，计划疗程____；
治疗目标为____。已核对____（过敏、肝肾功能、相互作用、禁忌）。
监测____；若出现____或至____仍未达到目标，则____。
```

缺少剂量、疗程、适应证或安全资料时，保留治疗类别和目的，并写【待医生确认】；不得根据模板自行补全。

## 五、首程、病程与出院的连贯性

- **首程**：提出问题清单、诊断层级、鉴别和初始计划，说明每项计划的目的。
- **日常病程**：记录新证据如何改变判断；围绕问题写“事实 → 评估 → 处理 → 复评”。
- **出院记录**：解释诊断演变、关键决策、治疗反应、未解决问题和出院后复评计划。

复杂病例可按系统书写；简单病例使用 problem-based 结构。无论哪种结构，都避免只写“病情平稳”“继续原治疗”而无证据和目标。
