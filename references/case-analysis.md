# 模式 B · 病情分析与治疗方案指导

本文件是模式 B（分析模式）的完整操作指引。**定位：面向执业医师的临床决策支持**——输出为指南引用的建议，由主治医师结合患者个体情况定夺；不面向患者使用；不虚构任何数据。

## 一、信息提取（含图片）

输入可以是文字、图片（化验单、检查报告、生命体征表、影像报告照片）或混合。

- **图片读取**：用视觉能力提取数值与单位，**保留原样**（如 `Hb 82 g/L`、`Na 128 mmol/L`），注明参考范围（如有）。
- **识别不可靠处**：模糊值、手写体不确定处、单位缺失、数值被遮挡——**逐项列入"请医生核实"清单**，绝不猜测补全。
- **多来源冲突**：文字与图片数据冲突时，分别列出并请医生确认，不自行取舍。
- **基本信息**：患者姓名、住院号、年龄、性别等若缺，先提问。

## 二、结构化临床数据

整理成表格摘要，字段：

| 类别 | 内容 |
|---|---|
| 一般情况 | 年龄、性别、主要症状及持续时间（主诉式概括） |
| 现病史要点 | 起病、演变、伴随症状、既往诊疗 |
| 查体 | 生命体征 + 阳性体征 + 关键阴性体征 |
| 辅助检查 | 按"常规 / 感染免疫 / 肿瘤标记 / 影像 / 病理"分类列异常值与参考范围 |
| 既往史与用药 | 慢性病、过敏史、当前用药（通用名） |

## 三、病情分析

**第一步：危重信号置顶识别。** 存在以下任一情况时，在报告顶部醒目标注"需紧急评估"：
- 生命体征异常：收缩压 <90 mmHg、心率 >130 或 <40 次/分、呼吸 >28 次/分、SpO₂ <90%、意识改变；
- 危急值：血糖 <2.8 mmol/L 或 >33.3 mmol/L、K⁺ <2.8 或 >6.5 mmol/L、Na⁺ <120 mmol/L、急性心肌损伤指标显著升高、出血性表现等；
- 临床综合征：休克、呼吸衰竭、急性肾损伤、肝性脑病、急性出血、DKA/HHS。

**第二步：按系统解读异常指标**，概括当前病情所处阶段（急性期/进展期/稳定期）、主要受累系统、与既往史的关系。

## 四、鉴别诊断

- 围绕主要表现列出候选诊断（3~5 个常见 + 需排除的重要诊断）。
- 逐条按"**支持 / 不支持**"给出依据，依据引用指南诊断标准。
- 明确"需要哪项检查来区分"（如：胸痛 → 肌钙蛋白/心电图；发热 → 血培养/炎症指标/影像）。

## 五、诊断倾向

- **只梳理医生已明确表述的诊断**，不代拟最终诊断。
- 对"待查"项，按指南给出**下一步检查建议**（标记物、影像、微生物学、病理等）及检查目的。
- 若材料不足无法判断，明确说明"信息不足"，列出尚缺的关键检查。

## 六、治疗方案建议

**指南检索策略**：按 [guidelines/README.md](guidelines/README.md) 三级策略执行——**先输出（检索不阻塞）→ 会话内缓存 → 轻量核对 → 按需深挖 → 失败兜底（版本待核实）**。

方案结构：
1. **治疗原则**：引用指南推荐（如"按《××指南（2024）》Ⅰ类推荐"）；核对**禁忌症与过敏史**（患者既往用药/过敏史缺失时明确提示）。
2. **具体方案**：药物用**通用名 + 剂量 + 用法 + 疗程**，来自指南；标注参考分级（Ⅰ/Ⅱa/Ⅱb）如有。
3. **监测与随访**：疗效指标、需复查项目、复查时机、观察不良反应。
4. **需紧急处理警示**：若病情存在急危倾向，置顶提示（如"若伴意识障碍需紧急评估，考虑 …"）。

**输出标注（简要）**：每条治疗建议附**指南名称 + 年份**；新旧指南冲突时以最新检索结果为准并注明差异；所引指南同步汇总进主输出后的**结尾信息块【指南依据】**。

## 七、输出结构（以"可直接插入病历的内容"为主）

**主输出 · 可直接粘贴的病例书写内容**（默认按首次病程记录结构，五部分完整成段，可直接复制进 HIS）：

```
首次病程记录

2026-08-05 14:30

病例特点：
1. 一般情况：____
2. 起病与症状：____
3. 既往史要点：____
4. 查体要点：____
5. 辅助检查阳性结果：____

初步诊断：
1. ____

诊断依据：
（1）____

鉴别诊断：
（1）与____鉴别：____

诊疗计划：
1. 检查计划：____
2. 治疗计划：____（药物通用名+剂量+疗程，标注指南名称与年份）
3. 护理与监测：____
4. 医患沟通：____

医师签名：________
```

- 把病情分析、诊断思路、治疗方案与指南引用**内联**进上述各段，而非独立成篇。
- 用户要求日常病程 → 按"一段话整合式"（客观输入→智能输出，见 [progress-note.md](progress-note.md)）；要求入院记录 → 输出对应片段。

**危重信号（置顶）**：如有危及生命的征象，先于主输出醒目标注一两行。

**结尾信息块（辅助，置后，不进 HIS）**：
1. **【待补充确认】**：缺失数据、模糊值、冲突项（按重要性排序）。
2. **【指南依据】**：本次引用指南（指南名 + 年份，简要）；无引用则省略。
3. 详细诊断推理与证据，仅在医生追问时展开。

**原则：让医生能直接复制粘贴的内容排第一，分析过程从简。**

## 八、安全守则
通用安全规则见 SKILL.md「安全与边界」。本节补充模式 B 特有事项：
- 若用户身份不是执业医师（疑似为患者或家属求医问药），应礼貌说明本工具面向医务人员，建议就医。
- 图片/文字中无的数据一律列入待核实，不补全。
