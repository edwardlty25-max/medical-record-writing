# 模式 B · 病情分析与治疗方案指导

本文件是模式 B（分析模式）的完整操作指引。**定位：面向执业医师的临床决策支持**——输出为指南引用的建议，由主治医师结合患者个体情况定夺；不面向患者使用；不虚构任何数据。

## 一、信息提取（含图片）

输入可以是文字、图片（化验单、检查报告、生命体征表、影像报告照片）或混合。

- **图片读取**：用视觉能力提取数值与单位，**保留原样**（如 `Hb 82 g/L`、`Na 128 mmol/L`），注明参考范围（如有）。
- **识别不可靠处**：模糊值、手写体不确定处、单位缺失、数值被遮挡——**逐项列入"请医生核实"清单**，绝不猜测补全。
- **多来源冲突**：文字与图片数据冲突时，分别列出并请医生确认，不自行取舍。
- **基本信息**：患者姓名、住院号、年龄、性别等若缺，先提问。

## 二、结构化临床数据

整理成表格摘要，字段：

| 类别 | 内容 |
|---|---|
| 一般情况 | 年龄、性别、主要症状及持续时间（主诉式概括） |
| 现病史要点 | 起病、演变、伴随症状、既往诊疗 |
| 查体 | 生命体征 + 阳性体征 + 关键阴性体征 |
| 辅助检查 | 按"常规 / 感染免疫 / 肿瘤标记 / 影像 / 病理"分类列异常值与参考范围 |
| 既往史与用药 | 慢性病、过敏史、当前用药（通用名） |

## 三、病情分析

**第一步：危重信号置顶识别。** 存在以下任一情况时，在报告顶部醒目标注"需紧急评估"：
- 生命体征异常：收缩压 <90 mmHg、心率 >130 或 <40 次/分、呼吸 >28 次/分、SpO₂ <90%、意识改变；
- 危急值：血糖 <2.8 mmol/L 或 >33.3 mmol/L、K⁺ <2.8 或 >6.5 mmol/L、Na⁺ <120 mmol/L、急性心肌损伤指标显著升高、出血性表现等；
- 临床综合征：休克、呼吸衰竭、急性肾损伤、肝性脑病、急性出血、DKA/HHS。

**第二步：按系统解读异常指标**，概括当前病情所处阶段（急性期/进展期/稳定期）、主要受累系统、与既往史的关系。

## 四、鉴别诊断

- 围绕主要表现列出候选诊断（3~5 个常见 + 需排除的重要诊断）。
- 逐条按"**支持 / 不支持**"给出依据，依据引用指南诊断标准。
- 明确"需要哪项检查来区分"（如：胸痛 → 肌钙蛋白/心电图；发热 → 血培养/炎症指标/影像）。

## 五、分级诊断与依据

先读取 [clinical-diagnosis.md](clinical-diagnosis.md)，再按“医生已确认 / 支持诊断 / 拟诊或待排除 / 资料不足”分级输出。

- **医生已确认诊断**：梳理其病史、查体、检查和动态变化依据，可在医生要求的病历正文中使用。
- **支持诊断**：仅在诊断支持区写“现有资料支持”，逐项列出支持依据与关键反证。
- **拟诊或待排除**：说明诊断缺口、需优先排除的疾病及区分检查，不代拟最终诊断。
- **资料不足**：明确缺失的决定性资料，不以概率或想象补齐。

## 六、治疗方案建议

**指南核验策略**：按 [guidelines/README.md](guidelines/README.md) 的风险分层策略执行。文书整理可直接进行；涉及具体诊断阈值、剂量、疗程、禁忌、相互作用或急危重决策时，须先核对权威来源。

方案结构：
1. **治疗原则**：说明适应证与目标；核对**禁忌、过敏史、肝肾功能、妊娠状态和相互作用**。关键资料缺失时先列待补充项。
2. **具体方案**：仅在适用人群、来源和关键个体信息均可核实时，给出**通用名 + 剂量 + 用法 + 疗程**；否则降级为治疗类别与核验事项。推荐分级必须与原指南一致，不凭记忆补写。
3. **监测与随访**：疗效指标、需复查项目、复查时机、观察不良反应。
4. **需紧急处理警示**：若病情存在急危倾向，置顶提示（如"若伴意识障碍需紧急评估，考虑 …"）。

**输出标注（简要）**：关键建议附**指南名称 + 年份 + 来源状态**；新旧指南冲突时说明差异，不自行拼接为新方案；所引指南汇总进【指南依据】。

## 七、输出结构

默认按以下顺序简明输出：

1. **危重提示**（如有）：需立即处置或复核的信号。
2. **临床问题摘要**：事实性概括，不夹带未确认诊断。
3. **分级诊断与依据**：诊断状态、支持/不支持事实、关键缺口。
4. **鉴别诊断**：优先排除项及区分检查。
5. **下一步建议**：检查、处理原则、监测与复评节点。
6. **【待补充确认】**：缺失、模糊或冲突信息。
7. **【指南依据】**：指南名称、年份、来源状态及核验日期；无引用则省略。

只有用户明确要求写入某类病历时，才读取对应模板并输出可粘贴的文书正文。模型分析、核验说明和免责声明放在正文之外。

## 八、安全守则
通用安全规则见 SKILL.md「安全边界」。本节补充模式 B 特有事项：
- 若用户身份不是执业医师（疑似为患者或家属求医问药），应礼貌说明本工具面向医务人员，建议就医。
- 图片/文字中无的数据一律列入待核实，不补全。
- 无法核验具体剂量、禁忌或适用人群时，不给出看似精确的个体化方案。
