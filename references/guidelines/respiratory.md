# 呼吸内科核心指南摘要

> 版本状态：**待核实**（编写于 2026-08，使用前先联网检索最新版（WebSearch/等效工具））。覆盖：慢阻肺、哮喘、社区获得性肺炎/HAP、肺栓塞、肺癌。

## 慢性阻塞性肺疾病（COPD）
- 最新版：《慢性阻塞性肺疾病诊治指南》及《国家基层慢阻肺病防治及管理实施指南（2025）》，使用前检索。
- **诊断**：症状（慢性咳嗽咳痰、活动后气短）+ 危险因素 + **肺功能：吸入支气管扩张剂后 FEV₁/FVC <0.70** 可确诊。
- **评估**：气流受限程度（GOLD 1~4 级）+ 症状（mMRC/CAT）+ 急性加重史 → 分组（A/B/E 或类似分组）。
- **稳定期治疗**：LABA/LAMA 为基础；急性加重高风险者优选含 LAMA 或 LABA+LAMA 双支扩，频繁加重者（≥2 次/年或 ≥1 次住院）加 ICS。戒烟、疫苗接种、肺康复是基础。
- **急性加重**：短效支气管扩张剂 + 糖皮质激素（泼尼松 40 mg/d×5d 或雾化）+ 氧疗目标 SpO₂ 88~92%；细菌感染征象（脓痰增多等）用抗菌药物；考虑无创通气（pH<7.35、PaCO₂ 升高伴嗜睡等）。

## 支气管哮喘
- 最新版：《支气管哮喘防治指南》（2020）及 GINA 更新，使用前检索 GINA 最新版。
- **诊断**：典型发作性喘息/气短/咳嗽 + 可变气流受限（支气管舒张试验、峰流速变异率、支气管激发试验之一）。
- **治疗**：ICS 为基石；GINA 建议 12 岁以上不以单一 SABA 治疗——按严重度使用 ICS-福莫特罗维持缓解或 ICS+LABA。按需加短效或 ICS-福莫特罗。
- **急性发作**：反复短效支气管扩张剂、全身糖皮质激素（早用）、吸氧；重度加雾化布地奈德-福莫特罗或静脉茶碱/硫酸镁（难治性）。

## 社区获得性肺炎（CAP）/ 医院获得性肺炎（HAP）
- 最新版：《中国成人社区获得性肺炎诊断和治疗指南（2016）》及更新、《医院获得性肺炎诊治指南》，使用前检索。
- **CAP 诊断**：新出现的咳嗽咳痰/原有加重 + 发热或胸痛 + 肺部体征 + 胸部影像（新发浸润影）+ 排除其他，多项成立。
- **严重度评估**：CURB-65 / PSI / 2020 版"死亡危险分层"决定住院 vs 门诊；重症（意识障碍、呼吸>30、收缩压<90、PaO₂/FiO₂<250 等）应收治 ICU。
- **经验性抗菌（门诊轻症）**：阿莫西林/头孢 + 大环内酯（或呼吸喹诺酮单药）；住院：β内酰胺类 + 大环内酯或喹诺酮。注意本地流行病学与耐药。

## 肺栓塞（PE）
- 最新版：《肺血栓栓塞症诊治与预防指南》，使用前检索。
- **诊断**：D-二聚体（低/中危可排除）+ 增强 CT（CTPA）确诊；超声心动图评估右心功能。
- **危险分层**：血流动力学不稳定=高危（需再灌注治疗）；余按简化 PESI 分中危/低危。
- **抗凝**：确诊后立即低分子肝素/磺达肝癸钠，过渡或直接 NOAC（利伐沙班、阿哌沙班等）；华法林 INR 2~3。疗程一般至少 3 个月，视诱因延长。
- **溶栓**：仅高危（低血压/休克）或无禁忌的中高危失代偿者。

## 肺癌
- 最新版：NCCN/CSCO 指南，使用前检索最新版。
- **诊断**：影像（低剂量 CT 筛查 50~74 岁高危人群）+ 病理活检（支气管镜/经皮穿刺）+ 分期（TNM）+ 分子分型（EGFR、ALK、ROS1、PD-L1、KRAS 等）。
- **治疗**：早期手术；局部晚期化放疗；晚期按驱动基因靶向（EGFR-TKI、ALK-TKI 等）或免疫治疗（PD-1/PD-L1）+ 化疗，依据分子分型个体化。

> 所有剂量与推荐分级以最新指南原文为准。
