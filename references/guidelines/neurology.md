# 神经内科核心指南摘要

> 版本状态：**2026-09-16 部分联网复核**——本次已复核：急性缺血性卒中（2023）、帕金森病（第四版，中华神经科杂志）；癫痫、周围神经病、偏头痛、重症肌无力、认知障碍、眩晕本次未能独立核实，沿用 2026-08-06 结论，使用前按三级策略核对。。覆盖：脑卒中、癫痫、周围神经病、帕金森病、偏头痛、重症肌无力、认知障碍/阿尔茨海默病、眩晕。剂量与推荐分级以各指南原文为准。

## 脑卒中（缺血性 / 出血性）
- 指南：《中国急性缺血性卒中诊治指南2023》（2024-06 发布）、《中国脑出血诊治指南（2019）》（2025 版如有正式发布，使用前检索）、《中国重症卒中管理指南2024》。
- **急性缺血性卒中评估**：ABC——气道/呼吸/循环 → **最后正常时间** → 立即 CT（鉴别出血）→ NIHSS 评分 → 血糖（低血糖可模拟卒中）。
- **再灌注（时间窗内）**：发病 4.5h 内**静脉溶栓（阿替普酶 0.9 mg/kg，最大 90 mg；或替奈普酶 0.25 mg/kg）**；大血管闭塞（颈内动脉、大脑中动脉 M1/M2）发病 6h 内（部分经影像筛选可至 6~24h）**血管内取栓（EVT）**。
- **急性期管理**：卒中单元、吞咽评估（防误吸）、血压管理（溶栓者 <180/110 mmHg；未溶栓者一般不急于降压，除非 >220/120）、血糖目标 7.8~10 mmol/L、抗血小板（溶栓后 24h 复查 CT 无出血再加）、尽早康复。
- **二级预防**：房颤者抗凝（NOAC）、非心源性缺血性卒中抗血小板（阿司匹林/氯吡格雷；轻型卒中或高危 TIA 短期双抗 21 天，CHANCE-2 基因指导可选替格瑞洛）、他汀（LDL-C <1.8，极高危 <1.4）、降压（目标 <130/80 可耐受）、戒烟限酒、控制血糖。
- **出血性卒中**：纠正凝血异常（华法林者维生素 K + PCC）、早期积极控制血压（SBP 目标 140 mmHg 左右）、颅内压管理（甘露醇/高渗盐水）、血肿清除指征（小脑出血 >3 cm 恶化者等）、长期抗栓权衡；重症脑出血按《中国重症卒中管理指南2024》监护（神经重症单元）。

## 癫痫
- 指南：《临床诊疗指南·癫痫病分册（2023修订版）》（中国抗癫痫协会，2023-03 出版）；分类用 ILAE 2017。
- **诊断**：两次非诱发性发作 ≥24h 间隔，或一次发作 + 未来 10 年复发风险 ≥60%（结构/遗传证据）——需详实病史（发作目击者描述）+ 脑电图 + 影像。
- **初始治疗**：单药起始、低剂量逐渐加量；局灶性——拉莫三嗪/左乙拉西坦/卡马西平/奥卡西平；全面性——丙戊酸/左乙拉西坦/拉莫三嗪（育龄期注意丙戊酸风险）。
- **难治性**：≥2 种合理 AED 足量仍发作，考虑癫痫中心评估手术/神经调控（耐药局灶性）。
- **持续状态（SE）**：>5 分钟不终止——先地西泮（静脉/经直肠）或劳拉西泮；一线无效即负荷左乙拉西坦/丙戊酸（无需心电监护、更安全），仍无效 30~60 分钟进入超难治状态（麻醉剂，需 ICU）；处理诱因（低血糖、电解质、感染、停药）。

## 周围神经病
- **评估路径**：起病方式（急性/亚急性/慢性）→ 分布（远端对称多发性、单神经、多发性单神经）→ 纤维受累（感觉/运动/自主神经）→ 神经传导/肌电图 → 病因筛查。
- **常见病因**：糖尿病、尿毒症、B12/维生素缺乏、甲状腺功能减退、酒精、药物（顺铂、胺碘酮、异烟肼）、炎症（GBS/CIDP）、结缔组织病、副蛋白血症/副肿瘤。
- **急性对称性**：警惕 AIDP（吉兰-巴雷综合征）——急性上升性无力 + 腱反射消失 + 脑脊液蛋白细胞分离；尽早静脉丙种球蛋白或血浆置换，监测呼吸功能（肺活量）。
- **治疗**：处理病因 + 对症（疼痛用加巴喷丁/普瑞巴林/三环类）+ 康复；CIDP 用免疫抑制（激素、IVIG）。

## 帕金森病（PD）
- 指南：《中国帕金森病治疗指南（第四版）》（中华医学会神经病学分会帕金森病及运动障碍学组）。
- **原则**：早诊断、早治疗；药物为首选且贯穿全程，手术为补充。
- **药物**：按年龄与运动并发症风险分层——复方左旋多巴（≥65 岁或认知受损者一线）、多巴胺受体激动剂、MAO-B 抑制剂、COMT 抑制剂；**避免突然停药（恶性综合征）**。
- **运动并发症**：剂末现象（COMT 抑制剂/分次给药）、异动症（减多巴胺剂量、加金刚烷胺等）；DBS 指征（药物难治性运动波动、无严重认知障碍）。
- **非运动症状**：便秘、睡眠障碍、抑郁、直立性低血压、认知障碍评估与综合管理。

## 偏头痛
- 指南：《中国偏头痛诊治指南（2022版）》（中国医师协会）与《中国偏头痛诊断与治疗指南（中华医学会神经病学分会第一版，2023）》。
- **诊断**：反复发作中重度搏动性头痛（4~72h）+ 恶心呕吐/畏光畏声；可伴先兆（视觉/感觉）。
- **急性期**：NSAIDs/对乙酰氨基酚；中重度用曲普坦（尽早）；吉泮类（2022 后获批，心血管安全性更优）；**每月不超过 2~3 天，防药物过度使用性头痛**。
- **预防（每月 ≥4 次或明显失能）**：β阻滞剂、托吡酯、氟桂利嗪、丙戊酸（育龄慎用）；CGRP 单抗/吉泮预防按适应证；建议记录头痛日记。

## 重症肌无力（MG）
- 指南：《中国重症肌无力诊断和治疗指南（2020版）》（2023 年后如有更新版使用前检索）；难治性全身型参考相关专家共识（2024）。
- **诊断**：波动性无力（晨轻暮重、疲劳试验）+ 新斯的明试验 + AChR 抗体（MuSK/LRP4）+ 重复电刺激递减。
- **治疗**：溴吡斯的明（对症）；激素（起始小剂量防加重）+ 免疫抑制剂（硫唑嘌呤、MMF、他克莫司）；难治性——靶向药物（补体 C5 抑制剂依库珠单抗、新生儿 FcRn 拮抗剂艾加莫德等，按获批情况）。
- **危象**：肌无力危象（呼吸衰竭）——ICU、呼吸支持、IVIG 或血浆置换；鉴别胆碱能危象（停溴吡斯的明）。

## 认知障碍 / 阿尔茨海默病（AD）
- 指南：《中国阿尔茨海默病痴呆诊疗指南》（2020 版；2025 更新版已发布，使用前检索确认）、《阿尔茨海默病源性轻度认知障碍诊疗中国专家共识2024》（2021 版更新）。
- **评估**：主诉认知下降 + 知情者证实 + 客观认知测验（MMSE/MoCA）+ 功能评估；**排除可逆原因（甲减、B12 缺乏、抑郁、药物、正常颅压脑积水）**；生物标志物（CSF Aβ/tau、PET、血浆 p-tau217 等）用于 AD 诊断与分期。
- **治疗**：胆碱酯酶抑制剂（多奈哌齐等，轻中度）、美金刚（中重度）；**抗 Aβ 免疫治疗（仑卡奈单抗等，2024 后按获批与 MRI 监测要求用于早期 AD）**；非药物（认知训练、运动、血管危险因素管理）；行为精神症状（BPSD）非药物优先。
- **照护**：安全（走失/跌倒）、驾驶评估、照护者支持；MCI 者定期随访与风险分层。

## 眩晕（头晕与平衡障碍）
- 指南：常见眩晕用药参考《甲磺酸倍他司汀治疗眩晕症的专家共识》（2023）；BPPV 参考《良性阵发性位置性眩晕诊断和治疗指南》（中华耳鼻咽喉头颈外科杂志 2017）；前庭性偏头痛参考国际诊断标准。
- **鉴别**：**BPPV**（体位诱发旋转性眩晕 <1 分钟，Dix-Hallpike 诱发，Epley 复位）；**梅尼埃病**（波动性眩晕 + 耳鸣 + 耳闷 + 波动性听力下降）；**前庭神经炎**（急性持续性眩晕 + 自发眼震 + 无听力障碍，激素 + 前庭康复）；**前庭性偏头痛**（中重度眩晕 + 偏头痛特征）；**中枢性眩晕**（脑干/小脑体征、复视、构音障碍——警惕后循环卒中，及时影像评估）。
- **处理**：BPPV——手法复位为主；前庭神经炎——短期激素 + 止吐 + 尽早前庭康复；梅尼埃——限盐 + 利尿 + 倍他司汀；老年眩晕——防跌倒与多病因评估。

> 所有剂量与推荐分级以最新指南原文为准。
