# 内科指南使用总则（模式 B 必读）

本目录捆绑**全内科亚专业**核心指南摘要，供模式 B（病情分析与治疗方案指导）与模式 A（病历书写中的诊断/鉴别诊断）使用。

## 轻量整合与路由

指南库不是每次病程生成的默认上下文。按任务按需读取：

| 任务 | 最小读取范围 | 输出要求 |
|---|---|---|
| 仅写首程、日常病程或出院记录 | 对应文书模板 + `rules.md` | 不主动加载指南；仅整理医生已确认事实 |
| 诊断依据、鉴别诊断、检查路径 | `../clinical-diagnosis.md` + 相关亚专业文件 | 分级诊断、事实依据、缺口和指南状态 |
| 治疗原则或推荐级别 | 上述资源 + 相关亚专业文件 | 标注指南名称、年份、来源状态和核验日期 |
| 具体剂量、疗程、阈值、禁忌、相互作用或急危重处置 | 上述资源 + 权威原文/说明书核验 | 未核验时仅给原则性建议并标注“版本待核实” |

诊断依据优先来自病例事实；指南用于说明诊断标准、检查路径或治疗原则，不能替代患者个体资料。

## 核验策略：按风险分层

指南迭代快，捆绑摘要只能作为路由和起点。根据输出风险选择核验深度：

### 1. 会话内缓存
同一疾病在**本会话中已核对过版本**，直接复用核对结论，**不重复检索**（记住本会话已核对的疾病清单）。

### 2. 低风险使用（文书整理与一般性分析）
不涉及具体阈值、剂量、禁忌或急危重决策时，可基于捆绑摘要整理事实和分析框架，并标注摘要版本。若声称“最新”或引用具体推荐级别，仍须核对原始来源。

### 3. 高风险核验（先核对、后建议）
- ① 捆绑摘要**未覆盖**该病；
- ② 涉及**具体剂量、疗程、禁忌、相互作用或高风险药物**（如抗凝、溶栓、胰岛素、化疗、血管活性药等）；
- ③ 医生**明确要求**最新指南全文确认；
- ④ **危急病情**需以最新决策依据支持。

### 核验失败时降级
检索失败、超时或无法访问原文时，可继续整理病例事实、危险信号和原则性处理框架，但不得把未核验摘要包装成当前个体化处方。标注“**版本待核实**”及捆绑摘要最后核对日期（2026-08-06），并列出需由医师核对的原指南、说明书或院内路径。

## 引用格式（简要）

关键治疗建议附：**指南名称 + 年份 + 来源状态**，并汇总进【指南依据】。示例：
> 正文：…按《中国高血压防治指南（2024年修订版）》…（2024）
> 【指南依据】：《中国高血压防治指南（2024年修订版）》（2024；原文已核验；核验日期：YYYY-MM-DD）

## 安全
- 摘要为临床决策支持参考，**不替代主治医师判断**；用药须核对禁忌、过敏史、肝肾功能与药物相互作用。
- 剂量为一般成人参考，具体以最新指南原文及药品说明书为准。
