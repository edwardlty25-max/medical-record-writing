# 病程与首程：写作原则与模板（一页版）

> 只留**原则 + 模板 + 句式 + 常见错**。时限、资质、签批位置等行政性要求见 [rules.md](rules.md)，本页不提。
> 配套示例：首程 first-progress-with-plan-example.md · 术前小结与查房 preop-summary-and-rounds-example.md · 术后病程 [postop-progress-example.md](examples/postop-progress-example.md) · 有手术的出院记录 discharge-with-procedure-example.md

## 一、五条总原则

1. **只写事实与判断**：事实（症状、体征、检验、操作）原样录；判断（考虑什么、为什么、下一步）写清依据。不写"病人一般可""继续观察"这类空话。
2. **事事有依据、有去向**：每个检查写"为什么做"，每个治疗写"为什么用、目标是什么"，每个异常写"下一步怎么办"。
3. **连续性**：今日记录必须与**昨日/术前/上次查房**对照（好转、加重、无变化都要写清对照）。
4. **自然叙述，不列台账**：写成一段诊疗叙述，按"事实 → 判断 → 处理 → 复评"流动；不写"住院期间多学科会诊及落实情况：××科……；××科……"。
5. **变更必留痕**：诊断变、治疗变、患者拒绝、上级指示，都要写清"依据 + 时间 + 影响 + 落实"。

## 二、日常病程：一段话 + 9 项数据

**当天写全这 9 项，缺项就留【待补充】**：① 症状演变（对比）② 生命体征 ③ 重点查体 ④ 新检验/检查（值 + 单位 + 参考范围）⑤ 治疗与医嘱变更（含理由）⑥ 操作/手术要点 ⑦ 会诊（科室 + 意见 + 采纳）⑧ 分析与计划（含复评条件）⑨ 医患沟通。

```
____年__月__日 __:__
患者____（症状较昨日/术前的变化、新发症状、饮食睡眠大小便），现予____（治疗：通用名 + 剂量 + 途径 + 频次，变更写理由）。
查体：T____℃  P____次/分  R____次/分  BP____/____mmHg；____（与本次问题相关的阳性体征复核 + 阴性体征）。
辅助检查：____（项目 + 数值 + 单位 + 参考范围；含正常但有意义的结果）。
会诊意见：____（科室 + 意见 + 本科采纳/未采纳及理由；无则删）。
综合分析：____（新事实支持或削弱原判断、病情好转/加重/平稳、诊断是否调整、治疗反应及变更理由），下一步诊疗计划：____（治疗目标、具体处理、监测项目、出现何种情况改为如何处理）。
已向患者及家属告知____，患者及家属表示____。
医师签名：________
```

**自然句式**（照这个口气写）

| 场景 | 写法 |
|---|---|
| 症状好转 | 患者未诉胸闷、胸痛，较昨日减轻 |
| 症状再发 | 昨夜再诉胸痛，予硝酸甘油静滴后缓解 |
| 检查支持判断 | 结合胸部 CT 示右肺上叶结节，考虑…… |
| 诊断变更 | 结合××检查结果，修正/补充诊断为××（见第五节） |
| 会诊影响决策 | 因胸痛，结合中医科会诊意见（考虑胸痹）加用中药汤剂 |
| 患者拒绝 | 建议××检查，患者因××拒绝，已告知××，改为×× |
| 计划与条件 | 继续××治疗；若出现××，则改为×× |

## 三、首程：五部分模板

```
首次病程记录

____年__月__日 __:__

病例特点：
1. 一般情况：____（年龄、性别、入院途径）
2. 起病与症状：因"____"入院，____（诱因、首发症状、特点、演变、伴随症状、有鉴别意义的阴性表现）
3. 既往史与危险因素：____
4. 查体要点：____（阳性体征 + 与鉴别相关的阴性体征）
5. 辅助检查：____（项目 + 数值 + 单位 + 参考范围 + 来源/时间）

初步诊断：
1. ____（主要诊断）
2. ____（严重程度/分型）
3. ____（影响处理的合并症）

诊断依据：____（逐条对应病例特点中的事实，不写套话）
鉴别诊断：____（2～4 项，每项写：支持点 / 不支持点 / 用什么检查区分；优先排除致命病）
诊疗计划：
1. 问题与目标：____
2. 检查计划：____（项目 + 目的 + 结果如何影响处理）
3. 治疗：____（通用名 + 剂量 + 途径 + 频次 + 疗程；有手术者写术前计划：术式 + 指征 + 术前检查 + 抗凝安排 + 替代方案）
4. 监测与调整：____（监测项目、目标值、出现何种情况改为如何处理）
5. 沟通与宣教：____（诊断不确定性、方案与风险、患者及家属意见）
医师签名：________
```

**病例特点的要害**：症状 + 危险因素 + 查体 + 检查数值**指向同一结论**，读得出诊断是怎么推出来的；有意义的阴性结果和检查来源必须写。

## 四、术前小结（有手术/介入就写）

**四要素**：指征 + 准备 + 风险 + 同意。缺一不可。

```
____年__月__日 __:__　术前小结
患者____（当前症状、生命体征、与手术相关的查体）。
术前诊断：1. ____　2. ____
手术指征：____（症状 + 检查依据 + 风险；不做的后果）
拟行手术：____（名称 + 部位/侧别，一句写清）
术前准备：____（术前检查结果有哪些异常或缺项、是否需要纠正；抗凝/抗血小板是否停用或桥接；禁食禁水、皮肤准备、备血、过敏史与肾功能核对）
手术风险：____（主要风险：出血、感染、麻醉风险、基础病加重等；对应防范措施）
替代方案：____（药物保守、其他术式、不手术的后果）
知情同意：____（已告知必要性、风险与替代方案；患者签署意见为"同意手术"，时间____）
医师签名：________
```

## 五、术后首次病程 + 连续记录

```
____年__月__日 __:__
今日在____（麻醉方式）下行____（术式全称），经过及所见详见手术记录。
术后患者____（神志、症状、有无胸闷胸痛/心悸/恶心、饮食大小便、出入量）。
查体：T____℃  P____次/分  R____次/分  BP____/____mmHg；____（切口或引流有无渗血渗液、红肿；相关部位末梢循环与感觉，与术前对比）。
辅助检查：____（术后复查：心肌损伤标志物、肾功能与电解质、血常规、心电图等，值与参考范围）。
用药：____（通用名 + 剂量 + 途径 + 频次）。
综合分析：____（手术是否达到预期、术后变化说明什么、并发症风险评估）。
下一步诊疗计划：____（体位与活动、监测项目与频次、复查项目与时间、用药调整与停用条件、水化与肾保护、出现何种情况立即处理）。
已向患者及家属告知手术结果、术后注意事项及风险，表示____。
医师签名：________
```

**术后第 1、2、3 天各记一次**，六要素：① 症状转归 ② 生命体征 ③ 切口或引流与局部情况 ④ 复查结果（术前 X → 术后 Y）⑤ 用药与调整 ⑥ 评估与计划。

## 六、上级查房：依据 → 判断 → 决策 → 落实

```
____年__月__日 __:__　____医师查房
经治医师汇报：____（当日情况）
查体：____（上级医师查到的要点）
分析：结合____（哪项新事实），考虑____（判断：诊断是否修正、治疗是否有效）
意见：____（具体决策：加/停/改用什么，剂量；监测什么；达到什么目标）
指示：____（下级需完成的事项）
落实情况：____（何时执行、执行到什么程度；未执行的写原因与替代）
医师签名：________
```

**三条硬要求**：写"依据→判断→决策"，不写"查房后指示继续观察"；每次查房要有**增量**（新检查/新调整/新计划）；上级指示要写**落实**。

## 七、四类常见情形的写法

| 情形 | 模板句 |
|---|---|
| **会诊** | "因____，结合____科会诊意见（考虑____）____（加用/调整/明确）____"；未采纳或患者拒绝写"建议____，患者因____拒绝，已告知____，改为____" |
| **修正/补充诊断** | "结合____（检查 + 数值 + 时间），修正/补充诊断为____；对治疗的影响：____" |
| **患者拒绝** | "建议____（目的与获益），患者/家属因____拒绝，已告知____风险与替代方案____，改为____，并____（随访/监测安排）" |
| **病情变化** | "____（时间）突发____（症状 + 体征 + 生命体征），考虑____，予____，____（复评结果）；下一步____" |

## 八、常见错（照着删）

1. "病情平稳，继续原治疗"——没有事实、没有依据、没有目标。
2. "查体同前""无异常"——要不写具体，要写"（-）"都不行（阴性体征逐系统写）。
3. "已请××科会诊，详见会诊单"——会诊意见与采纳情况必须自己写。
4. 诊断变更只在出院记录里出现，病程里查不到依据。
5. 上级查房只复述下级汇报、只写"继续观察"。
6. 术前只写"必要时手术"，无指征、准备、风险、替代方案。
7. 术后只写"手术顺利"，无切口或引流情况、无复查、无并发症观察。
8. 用药只写类别或商品名——通用名 + 剂量 + 途径 + 频次。
9. 时间不写到分、前后不一致（病程、手术记录、医嘱、护理记录互相对不上）。
10. 会诊、诊断变更、拒绝写成台账（"……及落实情况：××；××"），脱离诊疗叙述。
