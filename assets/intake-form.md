# 输入字段清单（给医生用）

**用法**：下面任选一种即可，**不必严格按格式填写**——

1. 整段口述 / 直接粘贴草稿；
2. 复制对应小节，逐行填写；
3. 直接粘贴化验单、检查报告、体温单的内容或照片。

**填不出的留空**：本技能不猜、不补造，会在成稿中标注【待补充】。

---

## 一、通用最小集（所有文书都建议提供）

| 字段 | 说明 |
|---|---|
| 患者 | 年龄、性别（姓名、住院号建议省略或脱敏） |
| 时间 | 入院时间、本次记录时间（`年-月-日 时:分`） |
| 主诉 | 症状/体征 + 部位 + 持续时间 |
| 现病史 | 起病诱因、首发症状、演变、伴随症状、就诊与检查经过、一般情况 |
| 既往史 | 慢病、手术外伤、输血、过敏、传染病、当前用药（通用名 + 剂量） |
| 查体 | 生命体征（T/P/R/BP）+ 阳性体征 + 有鉴别意义的阴性体征 |
| 检查结果 | 项目、数值、单位、参考范围、采样/报告时间 |
| 医生已确认诊断 | 初步 / 修正 / 补充 / 出院诊断 |
| 上级意见 | 查房分析、指示（如有） |
| 沟通 | 已告知患者/家属的内容与其意见（如有） |

## 七、交班 / 抢救 / 会诊 / 转科 / 死亡

```
交接班：患者、入院日期、交班日期、目前病情及诊治经过、本班次情况与处理、尚待解决的问题
抢救：开始时间、结束时间、病情变化（逐时生命体征与用药/操作）、结果、参与人员、补记时间（6 小时内）
会诊：申请科室、会诊科室、会诊时间、会诊意见、会诊医师签名
转科：入院日期、转科日期、病情及诊疗经过、转科原因、目前诊断、注意事项
死亡：死亡日期及时间、入院诊断、诊疗经过、死亡原因、死亡诊断、记录时间
```

## 八、图片 / 化验单

- 逐项保留**项目名 / 结果 / 单位 / 参考值 / 异常标记 / 采样时间**，不换算、不合并不同单位的结果。
- 模糊、遮挡、缺单位、手写不确定 → 该项标【待补充确认】，并在回复中集中列出需医生核实的条目。
- 报告自带「危急值 / Critical / ↑↑」标记 → 先置顶提示尽快复核处置（**只转述报告已有标记，不自行判定何为危急**）。
