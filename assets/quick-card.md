# 临床快用卡（一屏）

> 目标：**一次交互出稿**。急着用的时候只看这一页。

## 一句话用法

直接说：「写{入院记录 | 首次病程 | 日常病程 | 查房 | 交班 | 抢救 | 会诊 | 出院记录}」+ 口述或粘贴内容。
**不需要按格式整理**，顺口说即可。

## 最小输入（三项就能出稿）

| 给什么 | 例子 |
|---|---|
| 谁 | 55 岁女性（姓名可省，建议脱敏） |
| 时间 | 入院时间 / 本次记录时间（年-月-日 时:分） |
| 有什么 | 症状 + 查体关键项 + 已有检查结果（带单位与参考范围） |

其余缺项**一律标【待补充】**，不会猜、不会补造。完整字段见 [intake-form.md](intake-form.md)。

## 输出约定

- 默认只给**一个可直接粘贴进 HIS 的正文块**（不含提示语、不含免责声明、不含模型推理）；
- 缺项标【待补充】；需要你确认的内容列在正文之外；
- 药物写通用名；时间到分；数值带单位；阴性体征逐系统写。

## 三个最常用现场

| 现场 | 可以这样说 | 产出 |
|---|---|---|
| 早查房后 | 「写今天日常病程，3 床，昨晚间断咳嗽，今晨 T 37.8℃，血常规…」 | 一段病程：客观整合 + 分析判断 + 计划 + 沟通 |
| 新收病人 | 「写首程，55 岁女，发热 3 天，胸片示…」 | 五部分首程（病例特点 / 诊断 / 依据 / 鉴别 / 计划） |
| 出院当天 | 「写出院记录，住院 7 天，肺炎治愈出院，用药…」 | 出院记录（含四类医嘱与复诊安排） |

## 出稿后 10 秒自检

```bash
python scripts/validate_note.py 正文.txt --kind progress     # 出院用 --kind discharge
```

ERROR 必须改；WARN 需逐条确认（缺项提示属正常）。

## 三个最常见的坑

1. **主诉写成诊断**（“肺炎 3 天”）→ 改成“症状 + 部位 + 时间”（“发热伴咳嗽 3 天”）；
2. **阴性体征写“无异常”** → 逐系统具体描述（“双肺呼吸音清，未闻及干湿性啰音”）；
3. **出院医嘱漏“复诊安排”** → 患者拒绝或待查的项目，必须写清“建议做什么、何时复查、出现何情况须就诊”。
